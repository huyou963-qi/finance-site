# 本地用户事件

用自己的 AI 按 SKILL.md 和 Schema 生成 JSON，支持个股里程碑和跨资产专题。

1. 打开行情页，左侧选择「用户事件」，点击「导入」。
2. 选择 JSON，确认显示范围与新增／更新数量。
3. 查看导入结果；需要调整时使用「筛选」或「设置」。

文件只保存在当前浏览器的当前账号分区，不上传服务器，不跨设备同步。在「设置」中可逐个开关、导出，或删除并备份。换设备前请先导出，再在新设备导入。

提供稳定 pack.id，同一包按 externalId 更新、保留未提交记录；不同包同 ID 不覆盖。重导保留已有筛选、停用状态和未指定的配色。默认使用文件指定的显示范围，可在「设置 → 更多设置」调整导入范围。

「显示在 K 线」只控制图上标记，关闭后列表仍保留。未显示时点击事件「说明」，检查资产、日期和筛选。保留原始来源、完整 payload 和日期精度；不编造精确时刻，不自动发布到系统事件库。

本地文件不需要投递凭证、环境密钥或账号云同步。旧版私有投递接口已停用。持续采集由自己的 Skill 执行环境安排，生成文件后手动导入。

文件：README.md、SKILL.md、ingest-output.schema.json、example-TSLA.json。修改后运行 npm run pack:company-milestone 重建下载包。
