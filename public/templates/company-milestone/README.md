# 行情用户事件模板包

用自己的 AI 按 SKILL.md 与 Schema 生成 JSON。支持单标的里程碑与跨资产专题。PRIVATE_DELIVERY.md 说明账号私有投递、授权和重试。

## 文件导入

1. 打开 /markets，在底部左侧切换「用户事件」，打开「用户事件包管理」。
2. 默认按文件指定范围；也可选择「全部资产通用」或「仅当前标的」覆盖文件范围。
3. 选择 JSON，检查目标包、实际范围、新增/更新/未变，再确认导入。
4. 在「本次导入结果」查看当前可见数量和未显示原因。导入保留已有筛选、包开关及未指定的配色，不会为了显示而修改条件。

文件仅保存在同一浏览器站点的当前账号分区，不自动上传。提供稳定 pack.id，同包按 externalId 更新、保留未提交旧记录，不同包同 ID 独立保存。包可逐个启停、导出或删除并备份；重导相同文件不会复制事实。文件 scope 应明确；老文件无范围时兼容当前标的。

## Skill 账号私有投递

网站部署私有投递接口后，登录账号，在同一管理弹窗生成绑定某一包的 30 天凭证。按 PRIVATE_DELIVERY.md 投递，保存后网页在可见时每 30 秒检查更新，也支持手动刷新；跨浏览器登录相同账号可读取该云端包。云端包与同名本地包独立，网页不自动上传本地文件。

凭证只能写绑定包、不能读取用户数据，可替换或撤销。保存在可信执行环境的密钥变量，不能放入研究文件或日志。持续采集须由执行环境安排实际任务，下载 Skill 不会自动创建定时任务。
