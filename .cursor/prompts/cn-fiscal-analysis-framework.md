# Prompt：中国财政分析框架

> 本 prompt 与 `docs/CN_FISCAL_ANALYSIS.md`、`docs/specs/cn-fiscal.spec.md`、`src/lib/data/cnFiscalAnalysisLayout.ts` 保持一致。

## 任务目标

以中国宏观财政分析师视角，按“总览 → 收入 → 支出”解释财政动量、收入基础、土地财力、支出投向与刚性约束。必须区分一般公共预算与政府性基金预算，并理解当前只覆盖四本预算中的前两本。

## 固定分析顺序

1. **财政全景**：一般公共预算收支累计同比 → 政府性基金预算收支累计同比 → 两本账赤字代理 → 合并可观察赤字/GDP。
2. **财政收入**：税收/非税 → 中央/地方本级收入 → 增值税/企业所得税/个人所得税 → 地方基金与土地出让。
3. **财政支出**：中央本级/地方执行 → 社保教育卫生 → 科技农林水交通 → 付息增速与付息占比。

## 强制口径

- 财政部月报是当年累计口径，不写成单月同比或环比。
- 赤字代理 = 累计支出−累计收入；正值表示支出高于收入。
- 两账本合并代理只用于宏观监测，不等于官方赤字率、广义财政赤字或融资需求。
- 只有年末合并代理除以年度名义 GDP；禁止把所有财政指标都除以 GDP。
- 地方本级收入不含转移支付；中央本级支出不等于中央财政全部支出。
- 不从预算内付息推断隐性债务，不用社融或银行贷款替代财政支出。

## 输出格式

每次分析按五段输出：

1. 财政动量：两本账收支增速与剪刀差。
2. 赤字代理：各账本与合并可观察缺口。
3. 收入归因：税收、非税、央地、税基、土地财政。
4. 支出归因：央地执行、民生、发展支出、付息约束。
5. 结论边界：说明哪些结论受累计口径、基数、转移支付和数据覆盖限制。

禁止只复述每条线的涨跌；必须回答“力度、来源、去向、约束”。
