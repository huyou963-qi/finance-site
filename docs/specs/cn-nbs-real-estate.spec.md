# 中国国家统计局房地产开发与70城住房价格

## 覆盖口径

- `房地产开发与销售`：全国房地产开发投资、施工/新开工/竣工面积、新建商品房销售面积和金额、商品房待售面积、房地产开发企业本年到位资金；同时包括公开表1中的住宅、办公楼、商业营业用房及国内贷款、利用外资、自筹资金、定金及预收款、个人按揭贷款等子项。
- `70城住房价格`：70 个大中城市的新建商品住宅和二手住宅价格指数，分别保存“上月=100”“上年同月=100”“年内平均（上年同期=100）”这三个官方指数。

## 获取与合规

- 来源仅为国家统计局公开静态发布归档 `https://www.stats.gov.cn/sj/zxfb/`；房地产月报中的“相关数据表” `.xlsx` 和70城月报 HTML 表1、表2。
- `https://www.stats.gov.cn/robots.txt` 于 2026-08-08 返回 404；本接入只访问用户明确授权的公开统计发布页面，不访问受验证的国家数据接口，也不使用规避验证的逻辑。
- 请求设 30/60 秒超时，公开归档回填按每五秒最多一请求串行执行；日常 worker 只检查最新三页发布归档，进程内缓存24小时。

## 历史、修订和调度

- `data:seed-nbs-realestate` 读取公开归档（当前可获得 2021 年以来页面），建立全部指标订阅并写入历史；这是一次性后台回填命令，不能置于部署 SSH 会话。`data:seed-nbs-realestate -- --latest-only` 仅读取最近发布，用于 `data:apply` 的快速部署模式。`data:sync-nbs-realestate` 可再次幂等重跑全量历史，重新发布时同日期值会修订覆盖。
- 月度订阅由 `cn.nbs.real-estate` 发布包接入 `data:sync-calendar`；经济日历匹配不成功时，通用月度规则仍从发布窗口开始每日检查。70城价格和房地产开发月报分别按国家统计局实际发布时间抓取。
- 官方房地产表提供的是累计值/期末值与同比，不从累计值倒推单月、季度值或环比；70城价格仅存原始指数，不转换为推算涨跌幅。

## 目录与验证

- `catalogCategory` 分别为 `房地产开发与销售` 与 `70城住房价格`，由 `data:sync-catalog-layout` 写入中国目录树。
- 离线解析测试：`npx tsx src/lib/data/scheduler/nbsRealEstate/client.test.ts`；数据库自检：`npm run data:verify-nbs-realestate -- --db`。
