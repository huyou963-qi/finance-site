# 中国人民银行：货币与信用

## 1. 范围

接入中国人民银行公开发布的月度金融统计数据、社会融资规模存量及增量、贷款市场报价利率（LPR）。共 39 条序列：M0/M1/M2、人民币贷款和存款余额及同比、贷款和存款分部门累计增量、社融存量及同比、社融增量及主要分项、同业拆借/回购加权利率和 1 年期/5 年以上 LPR。

只保存公告直接披露的口径：余额、同比、当年累计增量或利率。人民银行未公开月度环比、独立季频或年频的分项不推算。

## 2. 官方获取方式

- [金融统计与社会融资规模归档](https://www.pbc.gov.cn/diaochatongjisi/116219/116225/index.html)：逐篇月报正文；金额统一由万亿元换算为亿元。
- [LPR 公告归档](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125440/3876551/index.html)：逐篇公告正文；2019 年 8 月改革后的 1 年期与 5 年以上 LPR。

网页缺少 HTTP charset 时，客户端优先按页面声明 UTF-8 解码，并为老页面回退 GB18030。解析器以公告标题的 `YYYY年M月` 确定观测月；LPR 以公告发布日期所在月确定观测月。找不到日期、数值或解析锚点时抛错，不写入可疑数据。

## 3. 合规、历史与调度

### 3.1 访问边界

2026-08-08，任务所有者明确授权对无需登录、无需付费的人民银行公开统计发布页进行自动获取。`https://www.pbc.gov.cn/robots.txt` 对通用爬虫为 Disallow；此授权仅适用于本任务的公共统计页面，不适用于登录、付费、验证码或其他技术访问控制。

历史回填顺序抓取、每个请求之间至少 300ms，并在单次进程内缓存 24 小时；不使用账号、Cookie、代理绕过或并发轰炸。香港部署通过既有 `CHINA_OFFICIAL_PROXY_URL` 的大陆 HTTP CONNECT 代理访问 `www.pbc.gov.cn`。

### 3.2 历史回填与未来更新

`npm run data:seed-pbc-monetary` 创建来源、指标和订阅；`npm run data:sync-pbc-monetary` 从公告归档幂等回填历史。订阅使用 `probe_interval: 24h`，现有每 5 分钟 worker 只会在到期时运行一次；同轮 39 条订阅共用一份 24 小时缓存。发布包 `cn.pbc.monetary-credit` 负责管理端分组。

## 4. 目录树

- `中国 > 银行与货币`：货币供应量、贷款/存款、社融及各融资分项。
- `中国 > 利率与债券`：同业拆借、回购与 LPR。

每条指标写入 `mds:pbc_cn_*` catalog key；seed 后执行 `data:sync-catalog-layout -- --prefix=mds:pbc_cn_ --dry-run`，确认后去掉 dry-run，以避免落入“未分配”。
