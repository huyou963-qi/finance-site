# 日本 METI 商业动态统计：零售销售

## 范围

首批接入 METI《商业动态统计调查》全国月度零售销售名义金额：零售业合计，以及综合商品、纺织服装及个人用品、食品饮料、汽车、机械器具、燃料、医药品及化妆品、其他、无店铺零售九个官方基础分类。单位为十亿日元，未季调。只保存源表直接公布的销售额，不从金额推算同比或环比。

该范围与已接入的总务省家计调查不重复：家计调查是需求侧每户支出，商业动态统计是供给侧商业企业销售额。库内检索未发现既有 `JP` 的 METI 零售销售 instrument。

## 官方源与获取方式

- 发布页：`https://www.meti.go.jp/statistics/tyo/syoudou/result-2/`
- METI长期时序：`https://www.meti.go.jp/statistics/tyo/syoudou/result-2/excel/h2slt11j.xlsx`
- e-Stat现行目录：`https://www.e-stat.go.jp/stat-search/files?cycle=0&layout=datalist&page=1&tclass1=000001081879&tclass2val=0&toukei=00550030&toukei_kind=6&tstat=000001081875`
- 工作表：`販売額（value）(月次M)`
- 获取方式：由 e-Stat 现行目录动态发现当年精确表题的 `statInfId`，下载 METI 官方静态 XLSX（`BULK_FILE` / `BULK_DOWNLOAD`），一次下载供十条序列复用；不固定易变的文件 ID。
- 节流：进程内缓存 60 秒；目录与文件请求串行化，最短间隔 2 秒；超时 30 秒。保存 SHA-256 原始快照、目录公布日、ETag、Last-Modified 和抓取时刻。

2026-09-13 实测：e-Stat 当前 `statInfId=000031387992`，公开日 2026-08-17，HTTP 200，文件 421,377 字节，源文件最新观测为 2026-06。METI 原站文件与 e-Stat 分发文件 SHA-256 相同。e-Stat 数据库表 `0003395211` 虽含业种销售额，但其目录更新时间为 2025-01-22，故不用于持续更新。

## 修订与断点

METI 长期表保存最新确报值，当年数据可能因年度补正改变。调度每次重读完整历史，由统一 writer 只写新增和修订，并把变动追加到版本账本。源注释标出多次定义或水准变化，其中 2020-03 与 2025-01 前后存在水准断点；无店铺零售从 2015-07 才开始表章。不得跨断点伪造增长率，也不得把后增分类的前期 `***` 当作零。

METI 公布时间表同时列速報与确报：通常月底 08:50 JST 发布上月速報，月中 13:30 JST 发布前一个月确报；本批长期表以确报更新为准。将来接官方日历时应绑定确报发布包，并在年度补正后完整回扫历史。

## 验证

- parser 按日文精确列名定位，不依赖易变列序；校验标题、月频时间码和 `10億円` 单位。
- 允许分类开始前的 `***`，但序列开始后缺月、未知文字、未来月份、重复/不连续月份均失败。
- `--live` 检查官方文件，`--db` 检查来源、订阅、发布包、首月、最新月、值域与 `nextRunAt`。
