## §1 分析框架

### 1.1 核心问题（L0）

中国金融条件究竟是在放松还是收紧：资金价格是否下降、银行体系流动性是否平稳、货币是否由“总量充裕”转为“交易活跃”，信用扩张是否真正改善，以及社融回升主要来自银行贷款、政府债券还是企业直接融资？

判断顺序不是简单罗列 M2、社融和 LPR，而是沿着以下传导链逐层验证：

`贷款定价与银行间资金价格 → 货币活性 → 信用总量 → 银行存贷扩张 → 融资结构`

只有多个环节同向，才能下“金融条件宽松/收紧”的结论；单独 M2 高增、LPR 下调或社融回升都不充分。

### 1.2 分析层级

| 层级 | 问题 | 主要指标（显示名） | 落到模板/图 |
|------|------|--------------------|-------------|
| L0 综合判断 | 价格、货币活性与信用是否共同指向宽松或收紧？ | LPR、银行间资金利率、M1/M2、社融与贷款同比 | ① 全部 + ②-1 |
| L1 贷款定价 | 银行对实体部门的报价利率是否下调，短端与中长期融资定价是否同步？ | 1 年期 LPR、5 年以上 LPR | ①-1 |
| L1 银行间流动性 | 有担保和无担保资金价格是否上行，二者价差是否扩大？ | 质押式回购加权平均利率、同业拆借加权平均利率、无担保−有担保价差代理 | ①-2 |
| L1 货币活性 | 流动性是否停留在广义货币，还是进入交易与经营性资金？ | M1 同比、M2 同比、M1−M2 增速差 | ①-3、①-4 |
| L1 信用总量 | 实体融资和银行贷款的存量增速是否企稳回升？ | 社融存量同比、人民币贷款余额同比 | ②-1 |

### 1.3 核心概念与口径边界

| 概念 | 本模板如何使用 | 不能怎样解释 |
|------|----------------|--------------|
| LPR | 观察银行贷款报价锚，1 年期偏一般贷款，5 年以上与中长期贷款、按揭定价更相关 | LPR 不是央行操作利率，也不能单独代表实际融资成本；没有扣除通胀和加点。 |
| 银行间同业拆借/质押式回购月均利率 | 观察无担保与有担保资金价格的大方向；二者差值是资金风险溢价的粗略代理 | 不是 DR007、R007、SHIBOR 或政策利率走廊；月均值会掩盖跨月末、税期等日内压力。 |
| M1、M2 同比 | M2 看广义货币扩张，M1相对 M2 的变化辅助判断交易性资金活跃程度 | M2 高增不等于资金进入实体；M1−M2 只是分析代理，不是官方“资金活化指数”。M1 口径调整前后需标注结构断点。 |
| 社融存量同比 | 判断实体经济从金融体系获得资金的存量扩张速度 | 不能把政府债券推动的社融回升直接解释为私人信用需求改善。 |
| 贷款−存款增速差 | 比较银行资产端信用扩张与负债端资金增长 | 不是存贷比、流动性覆盖率或银行流动性缺口；不能据此判断单家银行风险。 |
| 社融增量年内累计占比 | 用同月同口径累计分子/总社融累计，辨认融资渠道构成 | 每年 1 月重置且有季节性；分项可为负，占比可能小于 0 或大于 100%，四个展示分项也不构成完整 100%。 |

### 1.4 与现有及待建维度的分工

| 相邻主题 | 归属 | 本维度不做 |
|----------|------|------------|
| 中国通胀 | CPI、PPI、核心通胀及分项 | 不占用 CPI 构造实际 LPR，避免挤占未来通胀模板；需要判断实际利率时引用通胀维度。 |
| 中国增长与内需 | GDP、消费、投资、工业和地产 | 只判断金融条件是否形成支持，不用信贷数据代替实际需求和产出结果。 |
| 中国财政 | 两本预算收支、财政赤字代理、税收与支出结构 | 政府债券社融占比只用于识别信用结构，不解释财政力度；财政结论引用中国财政模板。 |
| 中国地产 | 房地产投资、销售、价格和开发资金 | 5 年以上 LPR只作中长期贷款报价锚，不重复地产量价指标。 |
| 中国外汇与国际收支 | 外汇储备、结售汇、跨境收付款、国际收支 | 不占用 SAFE 资金流指标，也不以外汇储备变化冒充汇率金融条件。 |
| 中国市场型金融条件（待扩展） | 国债收益率曲线、信用利差、汇率、权益风险与综合 FCI | v1 不用 legacy `chov_*` 或行情页数据拼接宏观模板，不发布“综合金融条件指数”。 |

### 1.5 结论纪律

1. “宽松”至少需要价格、货币活性、信用三类信号中的两类改善，且第三类不明显反向。
2. LPR 下调但 M1−M2 继续走弱、社融/贷款同比下行，应称“政策定价放松但传导偏弱”。
3. 社融同比企稳而人民币贷款同比仍弱、政府债券占比上升，应称“政府融资托底”，不能称私人信用复苏。
4. M1−M2 改善但贷款和社融仍弱，只能称交易性流动性改善，不能提前确认信用周期反转。
5. 银行间月均利率低位不等于所有市场主体融资容易；缺少信用利差和市场利率时必须保留结论边界。

规划两个 `layoutMode: 4` 的四图模板。模板 ① 先回答“资金松不松、钱是否活起来”，模板 ② 再回答“信用有没有扩张、由谁融资”。

| 顺序 | 模板 id | 名称 | 何时加载 |
|------|---------|------|----------|
| ① | `builtin-cn-financial-liquidity-funding` | 金融条件 · 资金价格与货币活性 | 默认第一步：判断贷款定价、银行间流动性和货币活性是否同向 |
| ② | `builtin-cn-financial-liquidity-credit` | 金融条件 · 信用扩张与融资结构 | 当总量信号改善或背离时：区分银行信用、政府融资与直接融资 |

## §4 图表介绍与分析方法

### 4.1 模板 description

- 模板 ①：从 LPR 贷款报价、银行间资金价格、M1/M2 增速到 M1−M2 增速差，判断流动性是否从“价格下降、总量充裕”进一步转化为交易和经营性资金活跃。
- 模板 ②：从社融与贷款存量增速进入银行贷存扩张，再拆银行信贷、政府债券与企业直接融资占比，判断信用改善的强度、资金来源和融资主体。

### 4.2 chartIntroNotes

**模板 ①**

1. 图 1：先看 1 年期和 5 年以上 LPR 是否同步下调。同步下行表示银行贷款报价锚放松，5 年以上降幅更大对中长期贷款和按揭更友好；但这只是政策定价信号，必须去图 2–4 检查资金面与货币活性是否跟随。
2. 图 2：再看质押式回购与同业拆借月均利率。两者同降表示银行间资金价格趋松；无担保利率相对有担保利率上升、价差扩大，只能视作资金风险溢价代理。若与图 1 背离，说明贷款报价调整尚未对应银行间资金条件改善。
3. 图 3：比较 M1 与 M2 同比。M2 企稳而 M1 继续弱，通常表示总量流动性未充分进入交易和企业活期资金；两者共同回升才是更广泛的货币扩张。接着去图 4确认相对强弱。
4. 图 4：M1−M2 由负收窄、转正，表示交易性货币相对活跃；继续走低则表示“钱多但不活”。该代理有口径与结构影响，必须到模板 ② 图 1检查信用总量，而不能单独确认复苏。

**模板 ②**

1. 图 1：先看社融存量与人民币贷款余额同比是否企稳回升。二者同步回升是广泛信用扩张；社融回升而贷款继续下行，意味着非贷款融资托底，转到图 3–4找来源。
2. 图 2：存款同比反映银行负债端资金增长，贷款−存款增速差上升表示资产端扩张相对更快。若贷款增长明显快于存款，不能直接称流动性危机，只能提示银行资金来源与信用扩张节奏分化，并回看模板 ① 图 2。
3. 图 3：比较社融口径人民币贷款与政府债券融资占比。银行贷款占比上升且图 1 贷款同比改善，更接近私人信用修复；政府债券占比上升而贷款偏弱，则是政府融资托底，应对照中国财政模板。
4. 图 4：企业债券与股票融资占比共同上升，说明直接融资渠道改善；若两者持续偏低且图 3 银行贷款占比高，实体融资仍依赖银行。占比为年内累计口径，每年 1 月重置，跨年拐点需谨慎。

### 4.3 决策树（观察 → 对照图位 → 典型结论）

| 观察 | 对照图位 | 典型结论 |
|------|----------|----------|
| LPR 下调，银行间资金利率也下行，M1−M2 改善，社融/贷款同比回升 | ①-1→①-2→①-4→②-1 | 金融条件由价格放松传到货币活性和信用，总体宽松信号较完整。 |
| LPR 下调，但 M1−M2 继续走弱，社融/贷款同比下行 | ①-1 vs ①-4、②-1 | 政策定价已放松但传导不足，不能仅凭降息称信用周期反转。 |
| M2 较强、M1 较弱，贷款同比下行 | ①-3、①-4 + ②-1 | 总量流动性充裕但资金活性和信用需求偏弱，存在“资金淤积”特征。 |
| 社融同比回升，贷款同比未回升，政府债券占比上升 | ②-1 + ②-3 | 社融由政府融资托底，不是私人部门信用广泛复苏。 |
| 社融与贷款同比回升，人民币贷款占比上升，直接融资也改善 | ②-1、②-3、②-4 | 信用扩张更广泛，银行与直接融资共同支持实体。 |
| 银行间资金利率上行、无担保−有担保价差扩大，但 LPR未变 | ①-2 vs ①-1 | 银行间资金条件边际收紧，尚未完全传至贷款报价；因只有月均值，需避免夸大短期压力。 |
| 贷款−存款增速差上升，而银行间资金利率同步上行 | ②-2 + ①-2 | 银行资产扩张相对负债更快，资金价格承压；这是系统节奏提示，不是单家银行风险结论。 |
| 企业债券/股票融资占比低，贷款占比较高 | ②-3 + ②-4 | 融资结构仍偏银行主导，资本市场直接融资传导较弱。 |

### 4.4 最终输出句式

模板结论应按“立场—传导—结构—边界”四段输出，例如：

> 贷款报价与银行间资金价格边际放松；M1−M2 负差收窄，货币活性有所改善；但社融企稳主要由政府债券占比上升驱动，人民币贷款同比仍弱，因此当前更接近“流动性宽松、私人信用传导有限”，而非全面信用扩张。由于缺少国债曲线、信用利差和汇率风险定价，本结论仅覆盖银行体系与信用传导，不代表完整市场 FCI。
