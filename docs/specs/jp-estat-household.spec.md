# 日本 e-Stat 家计调查接入

## 范围与复用门

2026-09-10 通过 e-Stat `getStatsList`、`getMetaInfo`、`getStatsData` 核验总务省统计局「家计调查・家计收支编・二人以上家庭」。仓库中没有同表、同家庭范围、同口径的既有序列，因此本批新增4条月度官方事实：二人以上家庭消费支出，及其中勤劳者家庭的消费支出、实收入、可支配收入。

本批全部是**名义、未季调、每户每月平均金额**。日文项目名“实收入”（`実収入`）是家庭实际收到的现金收入，不代表剔除物价后的实际收入。e-Stat这张金额表没有实质消费同比、实质金额或季调消费指数；本站不拿CPI自行平减，也不把发布稿增长率和金额拼成一条序列。

- `cdTab=01`：金额。
- `cdCat01=059/019/233`：消费支出、实收入、可支配收入。

## 目录、订阅与更新

- 目录：日本 → 国民经济 → 家庭消费与收入 → 月频。
- 复用`estat-jp`数据源、共享e-Stat client/adapter、统一scheduler、canonical observation writer和vintage表；不增加平行事实表或HTTP客户端。
- 发布包拟定为`jp.sbj.household_survey`，四条同表同批发布。目前采用24小时`probe_interval`，新月值最长约一天后发现；后续若接入统计局精确发布日历，再升级包级日历。
- 每次重读2000年以来完整历史以捕获官方修订。当前version ledger只证明抓取时点可见，不伪造历史首发PIT。

## 数据质量与边界

- parser必须固定表章、用途分类、家庭类型、地域全部四个非时间维度；维度漂移、单位变化、未知数值记法、重复月份和分页不完整均失败关闭。
- 官方当前表把现行家庭类型明确标注为“2000年起”，故不拼接旧`01/02`家庭分类。2018年起调查方法曾改进，但官方仍在同一现行序列中连续发布；本批按官方表保真，不擅自平移或断链。
- 实质消费的权威发布口径通常以同比变化等形式出现在统计局结果表/发布稿，不在本表API金额维度中。若后续接入，应作为独立静态文件源和独立指标，并核实基期、季调及修订方式。

## 验证计划

- 四份脱敏官方fixture分别固定四条筛选组合，断言319点、首末期、月度连续性和单位。
- `data:seed-jp-estat-household` → `data:seed-release-packages` → `data:sync-jp-estat-household` → `data:verify-jp-estat-household -- --db`。
- 统一worker重跑应为0新增、0改值；API Application ID只能从服务端环境读取，fixture与日志不得包含密钥。
