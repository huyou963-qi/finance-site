# 中国国有资本经营预算、社会保险基金预算接入

状态：verified（数据层验收通过，2026-10-21；生产定时触发未核验）。用户本轮明确授权接入第三、第四本账及修复既有财政数据更新；本任务只交付数据接入，不新增页面或内置模板。

## 1. 范围与复用门

- `reuse_needs_repair`：既有 `mof_cn_fiscal_*` 88 条，复用 `mof-fiscal` source、代码、解析器与 `cn.mof.fiscal` 发布包；修复特殊文本漏解析、历史回填、更新及调度日志，不创建平行月报源。
- `reuse_verified`：人民银行政府债券融资累计与财政性存款增加、BIS 政府杠杆率只作辅助，不重复抓取。
- `gap_new_source`：第三、第四本账年度决算，当前没有直接原始序列。使用财政部全国财政决算官方 HTML 表，provider=`mof_budget_accounts`，source=`mof-budget-accounts`，code=`mof_cn_budget_*`。
- 不接入估算、推算同比、拆月流量；年度预算数和执行数本轮不混入决算序列。

## 2. 指标及语义

财政部按全国、中央、地方分别披露国资收入/支出、社保收入/支出/结余，共15张表。catalog列出候选，seed先读取真实官方历史，只注册至少有一个观测的指标，不对源端空白填0。

- 第三本账：收支总量、利润/股息红利/产权转让/清算/其他收入，资本金注入、改革成本、公益补贴、补充社保、调出资金、结转等可取得科目。
- 第四本账：收支总量、缴费/财政补贴/利息/投资收益、当年结余/滚存结余；企业养老、机关养老、居民养老、职工医保、居民医保、失业、工伤、生育的实际公开分项。
- 单位亿元，年频，年度用当年1月1日存储。列必须为“决算数”，不得误读预算数或完成比例。
- 中央社保使用不含全国统筹内部调剂的收入/支出小计；全国不强行与中央+地方相加核对。
- 2025年部分中央行业统筹转地方；生育并入医保按原表，口径断点写入metadata。
- 最新同范围同表未再公布金额的历史分项保留观测，独立订阅暂停，不制造永不更新的僵尸指标；后续seed重新核验。
- 全新环境离线seed的历史项先启用一次引导，真实取到历史后自动归档，避免空库历史项永远无法回填。

## 3. 官方来源、fixture与更新

主入口：<https://yss.mof.gov.cn/>；全国决算目录例：<https://yss.mof.gov.cn/2025zyjs/>。早年目录不统一，通过核验的官方年度路径登记；后续年度从预算司首页公开链接发现，不把最新年硬编码为2025。

合规：只访问无需登录的政府公开统计表，不绕过任何认证/技术访问限制；使用明确UA、30秒超时、串行请求限速、共享promise缓存。本轮按用户明确的数据接入授权访问；robots/公共性实测记录由source模块交付。真实HTML fixture先存档再开发parser；结构变化、缺列、重复行、单位/年度错误必须失败告警。

- 年度决算：`cn.mof.budget_accounts_final`，probe_interval=168h；完整重读已公开年度以捕获决算修订。
- 原财政月报：`cn.mof.fiscal` 从无法可靠匹配的TE日历改为官方归档24h探测；稳态回读36个月修订窗口，空库和显式backfill可读完整历史。
- 所有同步经过既有dispatcher、runDataSubscription、upsertMacroObservations、fetch_run、版本账本和失败退避。
- probe包仅共享展示与获取缓存，不允许某个成员把其他成员排期统一推进；经济日历包维持既有共享排期语义。

## 4. 目录与部署

国家CN → 财政与公共债务 → 国资预算（全国/中央/地方）、社保基金（全国/中央/地方 × 总量/养老/医疗与生育/工伤与失业），自动按年频分组，单叶最多48条。`globalCatalogTaxonomy.ts` 定义落点，不依赖手工拖拽。
