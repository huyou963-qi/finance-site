## §1 分析框架

### 1.1 核心问题（L0）

中国经济增长是在改善、放缓还是仅由单一部门托底？领先订单能否传到生产和消费，GDP 增长由消费、资本形成还是净出口贡献，固定资产投资由制造业、基建还是房地产驱动，广义财政支出是否提供逆周期支撑，CPI/PPI 所反映的名义环境和进出口是否验证内外需修复？

本模板按以下顺序判断：

`实际/名义 GDP 与平减指数 → GDP 需求贡献 → 新订单领先信号 → 工业/消费/投资月度验证 → 固投三大领域驱动 → 广义财政支出 → CPI/PPI 名义环境 → 出口与进口交叉验证`

总览只在多项证据同向时给出增长状态。GDP 单季回升、新订单短期越过 50、出口高增或政策宽松，任何一个信号都不足以单独确认全面复苏。

### 1.4 核心口径与结论纪律

| 口径 | 正确用法 | 禁止解释 |
|------|----------|----------|
| GDP 实际/名义同比 | 实际同比看量，名义同比看以现价计价的收入规模变化 | 名义 GDP 增速不等于通胀；两者都受基数和核算修订影响。 |
| 隐含 GDP 平减指数同比 | 用同季名义 GDP/不变价 GDP 先构造隐含平减指数，再计算四季度同比，观察全经济广义价格 | 不用“名义增速－实际增速”的近似冒充精确值；平减指数也不等于 CPI 或 PPI。 |
| PMI 新订单 | 50 以上表示扩张性占比占优，拐点通常领先生产 | 扩散指数不是订单金额或增速；单月越过 50 不等于真实需求已强劲复苏。 |
| 工业增加值同比 | 同步观察供给端工业生产 | 规上工业不覆盖全部服务业和小微企业。 |
| 社零当月同比 | 观察商品零售与餐饮消费的月度变化 | 不代表全部居民消费、服务消费或实际购买力；未扣除 CPI。 |
| GDP 增长贡献率 | 三项合计解释当季 GDP 增长来源，可出现负贡献 | 是对“增长”的贡献率，不是 GDP 支出占比；不得把 60% 贡献率写成消费占 GDP 60%。 |
| 固投累计同比 | 观察年内投资趋势，总项与制造业、基建、房地产开发投资同为累计口径 | 1 月免报、年初重置；不能与当月社零/出口逐月幅度机械比较。 |
| 固投三大领域 | 总固投与制造业、基础设施、房地产开发投资累计同比共同观察，判断方向由哪一领域支撑或拖累 | 四条都是增速，不是贡献率或拉动百分点；在缺少连续分项权重时不得由增速直接推算贡献。房地产开发投资也不等同“房地产业固定资产投资”。基础设施统计范围发生变化时必须标注断点，不能静默拼接。 |
| 广义财政支出 | `一般公共预算支出累计额 + 政府性基金预算支出累计额`；同比必须对合计后的累计额做同月同比 | 不是两条官方同比的简单相加/平均；也不是完整的合并政府支出，未覆盖国有资本经营、社保基金及预算外活动。 |
| CPI/PPI 同比 | CPI 看居民端价格，PPI 看工业品出厂价格和企业名义环境 | PPI 回升不自动等于利润改善；CPI 低位也不单独证明通缩。 |
| 出口/进口美元同比 | 出口看外需与竞争力，进口兼具国内需求和价格因素 | 进口下降不能直接等同内需下降；需结合商品价格、加工贸易和国内生产。 |

结论至少遵守五条纪律：

1. “增长改善”至少需要领先订单与工业/消费/投资同步数据中的两类同向改善，并与最近季度实际 GDP 不明显冲突。
2. GDP 回升但社零、固投三大领域与进口偏弱，应称“总量改善但内生需求不足”，不能称全面复苏。
3. 净出口贡献和出口同比上升、进口同比走弱，应称“外需托底”，不能把贸易顺差扩大等同国内需求改善。
4. 总投资改善而制造业/房地产偏弱、基建较强且广义财政支出加速，应称“财政与基建托底”；不能直接推断私人资本开支周期已启动。
5. GDP 平减指数、CPI、PPI 同时偏弱且生产强于需求时，可称广义价格与名义需求不足具有多指标印证；在缺少工资和利润验证时仍不直接下“全面通缩”结论。

## §2 模板规划

规划两个 `layoutMode: 4` 的四图模板。模板 ① 集中完成 GDP 总量/名义锚、增长贡献、领先订单和月度硬数据判断；模板 ② 再拆固投三大领域，观察广义财政支出，并检查价格与外部需求。按人工评审要求，固定资产投资总项有一次有意重复：模板 ① 图 4 用于月度增长同步验证，模板 ② 图 1 用于投资结构基准；其余显示序列不跨模板重复。GDP 名义值在模板 ① 图 1 内同时承担名义同比显示和隐含平减指数输入。

实现约束（评审通过后由 Agent D 执行）：

- 先按季度日期对齐名义 GDP `N` 与不变价 GDP `R`，计算隐含平减指数水平 `D_t=N_t/R_t`，再对 `D_t` 做四季度同比。
- 四季度滞后按季度 category 匹配，不得把“数组前四项”当作固定滞后；缺季度、输入为空或分母为 0 时输出 `null`。
- 当前计算层可在原始序列上执行 `yoy`，但派生结果缺少后置同比能力。Agent D 只做通用的最小扩展（例如给 `MacroDerivedCalc` 增加可选 `postOp: "yoy"`），不得为中国 Overview 写页面内硬编码。
- 严禁用“名义 GDP 同比－实际 GDP 同比”替代上述精确公式；二者只在小幅变动下近似相等。
- 广义财政先按同一统计月对齐两条累计额再相加；任何一条缺失或未通过累计口径校验时，该月合计与同比均为 `null`，不得把缺失项当 0。
- 广义财政同比按上一年同一累计月份匹配，不能对相邻月环比年化；不能把一般公共预算支出同比和基金支出同比相加或平均。

## §4 图表介绍与分析方法

### 4.1 模板 description

- 模板 ①：先用季度实际/名义 GDP 与精确隐含平减指数判断量、价和名义收入，再拆 GDP 三大需求贡献，观察制造业/非制造业新订单，并用工业、社零和固投验证月度增长脉冲。
- 模板 ②：先把总固投拆成制造业、基建和房地产三大领域驱动，再观察两本账合计的广义财政支出规模与同比，最后用 CPI/PPI 和出口/进口验证名义环境与内外需。

### 4.2 chartIntroNotes 草稿

**模板 ①：中国经济 Overview · 增长脉冲**

1. 图 1：实际 GDP 同比看“量”，名义 GDP 同比看现价收入规模，隐含平减指数同比看全经济广义价格。实际强而名义/平减指数弱属于量强价弱；三者共同改善才更支持名义增长修复。平减指数按名义值与不变价值之比精确计算，不使用名义减实际的近似。
2. 图 2：拆最终消费、资本形成与净出口的 GDP 增长贡献。消费和资本形成共同改善更接近内需修复；净出口单独抬升属于外需托底。贡献率不是 GDP 占比，负贡献必须保留。
3. 图 3：观察制造业与非制造业新订单是否向上并站在 50 以上。两者共同改善是更广泛的需求领先信号；仅一项改善意味着行业分化，转到图 4 确认生产、消费和投资谁在跟随。
4. 图 4：工业和社零是当月同比，固投是年内累计同比；主要比较方向和拐点，不机械比较单月幅度。三者共同改善才更接近供需共振；工业强、社零/固投弱则提示供给强于内需。完成后进入模板 ② 拆投资驱动、财政支撑、价格和外部需求。

**模板 ②：中国经济 Overview · 需求结构与政策支撑**

1. 图 1：以总固投累计同比为基准，对照制造业、基础设施和房地产开发投资累计同比。制造业强通常指向产业资本开支，基建强而其他两项弱更像政策托底，房地产深度负增长则可能持续拖累总投资。四条都是增速，只表达贡献方向，不能直接相加，也不能写成各自的贡献率或拉动百分点；基建统计范围变化处必须显示口径断点。
2. 图 2：广义财政支出累计额为一般公共预算支出与政府性基金预算支出之和，柱看年内规模、线看合计后的累计同比。增速回升且规模扩张表示财政支出端支撑增强；基金支出受土地收入、专项债与项目进度影响，需回到中国财政模板拆解来源。该指标是两本账支出代理，不是完整合并政府支出。
3. 图 3：比较 CPI 与 PPI。两者共同回升且增长数据改善，名义收入环境更有利；PPI 深度负增长而生产偏强，提示量强价弱和企业收入压力。CPI/PPI 是结构价格验证，不替代模板 ① 的 GDP 平减指数。
4. 图 4：用出口与进口当月同比交叉验证。出口和进口共振上行通常对应内外需改善；出口强、进口弱更像外需托底或价格影响。若与模板 ① 图 2 的净出口贡献同向，可提高外需主导判断的置信度。

### 4.4 最终输出句式

结论按“增长状态—领先/同步验证—驱动结构—名义环境—政策复核”五段输出，例如：

> 实际 GDP 增速边际企稳，但名义 GDP 与隐含平减指数仍弱；制造业与非制造业新订单有所改善，工业生产也在回升，但社零偏弱；总固投主要由基建支撑，制造业投资放缓、房地产开发投资仍在收缩，广义财政支出同比回升；增长贡献主要来自净出口，出口强于进口，CPI/PPI 仍处低位。因此当前更接近“财政、基建和外需托底，居民与企业内生需求修复有限”，而非全面扩张。下一步应到中国财政和金融条件模板分别拆解两本账来源与信用传导。
