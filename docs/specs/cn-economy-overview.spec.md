## §1 分析框架

### 1.1 核心问题（L0）

中国经济增长是在改善、放缓还是仅由单一部门托底？领先订单能否传到生产和消费，GDP 增长由消费、资本形成还是净出口贡献，民间投资和进口是否验证内生需求，CPI/PPI 所反映的名义环境是否支持企业收入与利润修复？

本模板按以下顺序判断：

`实际 GDP 增长锚 → 新订单领先信号 → 工业与消费同步验证 → GDP 需求贡献 → 总投资与民间投资 → CPI/PPI 名义环境 → 出口与进口外需/内需交叉验证`

总览只在多项证据同向时给出增长状态。GDP 单季回升、新订单短期越过 50、出口高增或政策宽松，任何一个信号都不足以单独确认全面复苏。

### 1.4 核心口径与结论纪律

| 口径 | 正确用法 | 禁止解释 |
|------|----------|----------|
| GDP 实际同比 | 作为季度增长锚，判断同比趋势 | 不等同季度动能；基数效应较大时必须由月度数据验证。 |
| PMI 新订单 | 50 以上表示扩张性占比占优，拐点通常领先生产 | 扩散指数不是订单金额或增速；单月越过 50 不等于真实需求已强劲复苏。 |
| 工业增加值同比 | 同步观察供给端工业生产 | 规上工业不覆盖全部服务业和小微企业。 |
| 社零当月同比 | 观察商品零售与餐饮消费的月度变化 | 不代表全部居民消费、服务消费或实际购买力；未扣除 CPI。 |
| GDP 增长贡献率 | 三项合计解释当季 GDP 增长来源，可出现负贡献 | 是对“增长”的贡献率，不是 GDP 支出占比；不得把 60% 贡献率写成消费占 GDP 60%。 |
| 固投累计同比 | 观察年内投资趋势，总项与民间投资同口径比较 | 1 月免报、年初重置；不能与当月社零/出口逐月幅度机械比较。 |
| CPI/PPI 同比 | CPI 看居民端价格，PPI 看工业品出厂价格和企业名义环境 | PPI 回升不自动等于利润改善；CPI 低位也不单独证明通缩。 |
| 出口/进口美元同比 | 出口看外需与竞争力，进口兼具国内需求和价格因素 | 进口下降不能直接等同内需下降；需结合商品价格、加工贸易和国内生产。 |

结论至少遵守五条纪律：

1. “增长改善”至少需要领先订单与工业/消费同步数据中的两类同向改善，并与最近季度 GDP 不明显冲突。
2. GDP 回升但社零、民间投资与进口偏弱，应称“总量改善但内生需求不足”，不能称全面复苏。
3. 净出口贡献和出口同比上升、进口同比走弱，应称“外需托底”，不能把贸易顺差扩大等同国内需求改善。
4. 总投资改善而民间投资偏弱，应优先检查财政和政府融资，不能直接推断企业资本开支周期已启动。
5. CPI/PPI 同时偏弱且生产强于需求时，可称名义需求不足或价格压力偏弱；在缺少 GDP 平减指数、工资和利润验证时不直接下“全面通缩”结论。

## §2 模板规划

规划两个 `layoutMode: 4` 的四图模板。模板 ① 先判断增长方向和月度脉冲；模板 ② 再解释增长来源、内生投资、名义价格和外部需求。两个模板原始序列零重复。

| 顺序 | 模板 id | 名称 | 何时加载 |
|------|---------|------|----------|
| ① | `builtin-cn-economy-overview-pulse` | 中国经济 Overview · 增长脉冲 | 默认第一步：快速判断增长、领先订单、生产和消费是否同向 |
| ② | `builtin-cn-economy-overview-balance` | 中国经济 Overview · 需求结构与名义约束 | 第二步：解释 GDP 来源，检查民间投资、价格环境和外需/进口 |

### 模板 ①：中国经济 Overview · 增长脉冲

| 图 | slotTitle | 序列（显示名） | 轴 | 图型 |
|----|-----------|----------------|----|------|
| 1 | 实际增长锚：GDP 同比 | 季度国内生产总值实际同比 | left | `timeSeries/line` |
| 2 | 需求领先：制造业 vs 非制造业新订单 | 制造业 PMI 新订单；非制造业 PMI 新订单 | left | `timeSeries/line+line` |
| 3 | 生产同步：规上工业增加值 | 规模以上工业增加值同比 | left | `timeSeries/bar` |
| 4 | 消费同步：社会消费品零售总额 | 社会消费品零售总额当月同比 | left | `timeSeries/bar` |

设计理由：GDP 负责定季度增长状态，新订单负责领先判断，工业与社零分别验证供给和消费。四图不强行把季频 GDP 与月频序列叠在同轴，也不把工业和社零合成一个“经济指数”。

### 模板 ②：中国经济 Overview · 需求结构与名义约束

| 图 | slotTitle | 序列（显示名） | 轴 | 图型 |
|----|-----------|----------------|----|------|
| 1 | GDP 增长贡献：消费、资本形成、净出口 | 最终消费支出增长贡献率；资本形成总额增长贡献率；货物和服务净出口增长贡献率 | left | `timeSeries/stackBar`（同一 stackGroup，保留负贡献） |
| 2 | 投资主体：总投资 vs 民间投资 | 固定资产投资累计同比；民间固定资产投资累计同比 | left | `timeSeries/line+line` |
| 3 | 名义环境：CPI vs PPI | 居民消费价格同比；工业生产者出厂价格同比 | left | `timeSeries/line+line` |
| 4 | 外需与进口验证：出口 vs 进口 | 出口总额当月美元同比；进口总额当月美元同比 | left | `timeSeries/bar+bar` |

设计理由：图 1 用官方当季增长贡献率回答 GDP “由谁拉动”，不是支出占比；图 2 观察投资是否有民间部门参与；图 3 判断居民端和生产端名义价格；图 4 用出口与进口区分外需托底、内需/价格偏弱或内外需共振。

## §4 图表介绍与分析方法

### 4.1 模板 description

- 模板 ①：从季度实际 GDP 进入制造业/非制造业新订单，再用工业增加值和社零验证领先景气是否传到生产与消费，形成中国增长方向的第一轮判断。
- 模板 ②：用 GDP 三大需求贡献解释增长来源，再检查总投资与民间投资、CPI/PPI 以及出口/进口，区分内生需求修复、政策托底和外需拉动。

### 4.2 chartIntroNotes 草稿

**模板 ①：中国经济 Overview · 增长脉冲**

1. 图 1：先用季度实际 GDP 同比确定增长锚。同比回升只说明相对上年改善，遇到低基数或单季波动时不能直接判复苏；随后到图 2–4检查领先订单和月度硬数据。
2. 图 2：观察制造业与非制造业新订单是否向上并站在 50 以上。两者共同改善是更广泛的需求领先信号；仅一项改善意味着行业分化，转到图 3–4确认生产和消费谁在跟随。
3. 图 3：看规上工业增加值同比是否跟随新订单。订单上行而工业未改善，说明传导尚未兑现；工业强而订单走弱，则提示当前生产可能领先信号不足，需警惕后续放缓。
4. 图 4：看社零当月同比是否与工业共同改善。工业强、社零弱通常是供给强于居民需求；两者共同回升才更接近实体供需共振。完成后进入模板 ② 检查增长来源和名义环境。

**模板 ②：中国经济 Overview · 需求结构与名义约束**

1. 图 1：先拆最终消费、资本形成与净出口的 GDP 增长贡献。消费和资本形成共同改善更接近内需修复；净出口单独抬升属于外需托底。贡献率不是 GDP 占比，负贡献必须保留。
2. 图 2：再比较总固投与民间投资累计同比。二者同升表示投资扩张更广；总投资改善、民间投资偏弱时转到中国财政和金融条件模板，检查政府投资托底与私人信用传导。
3. 图 3：比较 CPI 与 PPI。两者共同回升且增长数据改善，名义收入环境更有利；PPI 深度负增长而生产偏强，提示量强价弱和企业收入压力。CPI/PPI 不能替代 GDP 平减指数。
4. 图 4：最后用出口与进口当月同比交叉验证。出口和进口共振上行通常对应内外需改善；出口强、进口弱更像外需托底或价格影响。若与图 1 净出口贡献同向，可提高外需主导判断的置信度。

### 4.3 决策树（观察 → 对照图位 → 典型结论）

| 观察 | 对照图位 | 典型结论 |
|------|----------|----------|
| GDP 同比、新订单、工业和社零共同回升 | ①-1→①-2→①-3/4 | 增长改善由领先和同步数据共同确认，进入模板 ②判断驱动质量。 |
| GDP 回升，但新订单低于 50、工业和社零未跟 | ① 全部 | 季度总量改善缺少月度扩散，可能受基数或单一部门拉动，暂不确认持续复苏。 |
| 新订单上升，工业尚弱，社零改善 | ①-2→①-3/4 | 需求领先信号改善、消费先行，但生产传导尚待兑现。 |
| 工业强、社零弱、PPI偏弱 | ①-3/4 + ②-3 | 供给强于居民需求且量强价弱，名义增长质量有限。 |
| 最终消费与资本形成贡献上升，民间投资改善，进口回升 | ②-1/2/4 | 内生需求修复证据较完整，增长对外需单一依赖下降。 |
| 净出口贡献上升、出口强而进口弱 | ②-1 + ②-4 | 外需托底增长，但进口未确认内需改善；不能把顺差扩大写成全面复苏。 |
| 总固投回升、民间投资继续偏弱 | ②-2 + 中国财政/金融条件模板 | 投资更可能由政府或国有部门托底，私人部门资本开支信心不足。 |
| CPI/PPI共同偏弱，社零、民间投资、进口也弱 | ②-2/3/4 + ①-4 | 名义需求不足具有多指标印证，但在工资、利润和平减指数缺失下仍避免“全面通缩”定性。 |
| 政策宽松但新订单、社零、民间投资未改善 | 中国金融条件/财政模板 + ①-2/4 + ②-2 | 政策立场已转松但向私人需求传导有限。 |

### 4.4 最终输出句式

结论按“增长状态—领先/同步验证—驱动结构—名义环境—政策复核”五段输出，例如：

> 实际 GDP 增速边际企稳，制造业与非制造业新订单有所改善，工业生产也在回升，但社零仍偏弱；增长贡献主要来自净出口，民间投资未随总投资同步走强，出口强于进口；CPI/PPI 仍处低位，因此当前更接近“外需和投资托底、居民与私人内需修复有限”，而非全面扩张。下一步应到中国财政和金融条件模板判断托底来源与信用传导。
