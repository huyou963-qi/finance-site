## §1 分析框架

### 1.1 核心问题（L0）

中国财政是在扩张还是收缩，这种变化来自收入基础、土地财政还是支出加力；中央与地方的执行节奏有何差异；付息等刚性支出是否正在压缩可用于稳增长和公共服务的财政空间？

### 1.2 阅读顺序

1. 先看模板 ①，把两本主要账放在一起比较收入、支出增速，再看可观察赤字及其占 GDP 比例。
2. 若收入走弱，进入模板 ②，区分税收、非税、中央/地方和土地财政。
3. 若支出加速或财政效果偏弱，进入模板 ③，判断中央/地方执行、民生支出、发展支出和付息压力。
4. 最终结论必须同时回答：力度、来源、去向、约束，不以单一“支出同比较高”代替财政判断。

### 1.4 中国财政口径地图

中国政府预算体系通常包含四本预算：一般公共预算、政府性基金预算、国有资本经营预算、社会保险基金预算。本维度 v1 数据覆盖前两本，也是宏观周期与土地财政分析最重要的两本；它不是“四本账合并财政”。

| 口径 | 本模板如何使用 | 不能怎样解释 |
|------|----------------|--------------|
| 一般公共预算 | 税收、非税、中央/地方收入及公共服务和发展支出 | 支出−收入只能称该账本的“赤字代理/收支缺口”，因存在调入、结转结余等项目。 |
| 政府性基金预算 | 土地出让相关收入与基金支出 | 可与一般预算并列及构造“两账本合并可观察赤字代理”，但不得冒充官方财政总赤字。 |
| 中央收入 vs 地方本级收入 | 比较收入端央地变化 | 地方本级收入不含中央转移支付，不能据此直接判断地方可支配财力。 |
| 中央本级支出 vs 地方支出 | 比较执行主体 | 中央本级支出不等于中央财政全部支出，转移支付大部分最终体现为地方支出。 |
| 月度金额与同比 | 使用财政部公布的当年累计额、累计同比 | 不从累计值倒推官方未发布的单月同比或环比；1–2 月合并期尤其不可拆分。 |
| 赤字/GDP | 两账本 12 月累计支出之和减收入之和，再除同年年度名义 GDP | 只在年末生成；名称必须带“可观察代理”，不等于官方赤字率或广义财政赤字率。 |

### 1.5 与相邻维度分工

| 相邻维度 | 归属 | 本维度边界 |
|----------|------|------------|
| 中国增长与内需 | GDP、消费、投资、工业 | GDP 只作年度分母；财政对增长的结果在增长模板解释。 |
| 中国地产 | 销售、投资、施工、70 城房价 | 本维度只观察土地出让收入和基金预算这一财政传导终点。 |
| 中国货币与信用 | 货币、贷款、社融、LPR | 不以社融或银行贷款替代财政支出。 |
| 政府债务与融资（待建） | 国债、地方债、专项债发行及债务余额 | v1 仅用预算内债务付息观察刚性约束，不推断隐性债务。 |
| 国有资本与社保基金（待扩展） | 其各自预算收入、支出与结余 | 当前数据未覆盖，不混入前两本预算。 |

## §4 分析文案

### 4.1 模板 description

- 模板 ①：先把一般公共预算和政府性基金预算放在同一分析链条中，比较两账收入与支出累计同比，再计算各自及合并可观察赤字代理，最后只对合并赤字使用 GDP 标准化。代理赤字不是官方赤字率。
- 模板 ②：从一般公共预算收入总盘进入税收/非税、中央/地方本级收入和主要税基，最后落到政府性基金与土地出让，判断收入压力来自经济税基还是地产财力。
- 模板 ③：从模板 ① 的一般公共预算总支出进入中央本级与地方执行、民生和发展投向，再以债务付息增速和付息占比判断刚性支出是否挤压财政空间。

### 4.2 chartIntroNotes

**模板 ①**

1. 图 1：先看一般公共预算收入与支出累计同比的剪刀差。支出快于收入且差距扩大，说明常规预算账本的可观察资金缺口增加；再去模板 ② 判断收入原因、模板 ③ 判断支出去向。
2. 图 2：用相同方法看政府性基金预算收支。收入更受土地和项目周期影响，收入走弱而支出维持通常意味着基金账本承压；再到模板 ② 图 4检查土地财力。
3. 图 3：先列两本账各自“支出−收入”，再给出两账本合并可观察赤字代理。正值扩大表示可观察资金缺口增加；由于未处理调入、调出和重复关系，它不是官方赤字。
4. 图 4：只在最后将年末两账本合并可观察赤字除以同年名义 GDP，用于跨年比较缺口相对经济规模的变化。该比率必须带“可观察代理”标签，不与官方赤字率混称。

**模板 ②**

1. 图 1：模板 ① 已给出一般公共预算总收入，本图只拆税收与非税。税收弱、非税强可能意味着经济税基偏弱且地方通过盘活资产、罚没或其他非税渠道补充财力，需谨慎解释其可持续性。
2. 图 2：中央收入和地方本级收入用于识别压力落在哪一级；地方本级收入不含转移支付，因此不能与地方支出直接相减得出地方缺口。
3. 图 3：增值税更贴近生产流通，企业所得税受利润和汇算清缴影响，个人所得税反映居民收入及政策变化。三者共同走弱比单一税种波动更能说明税基压力。
4. 图 4：地方基金预算本级收入与土地出让收入同向走弱，说明土地财政拖累较广；再回模板 ① 图 1 对照全国基金收入，区分地方土地压力和其他基金项目变化。

**模板 ③**

1. 图 1：模板 ① 已给出一般公共预算总支出，本图只比较中央本级与地方执行。地方支出承担大量公共服务与项目执行，但其资金来源包含中央转移支付，央地两线只反映执行节奏。
2. 图 2：社保就业、教育和卫生健康衡量民生托底。三者共同加速表示公共服务支出扩张；单项跳升需检查基数和专项政策。
3. 图 3：科技、农林水和交通运输对应创新、农业水利与交通基础设施。持续高于总支出增速才更能说明发展性支出倾斜。
4. 图 4：观察付息增速与付息占比，再回看图 1 的总支出增速。付息增速更快且占比上升，意味着刚性负担挤压其他预算空间；这只能说明预算内付息约束，不能据此估计隐性债务。

### 4.3 财政判断五问

| 顺序 | 问题 | 先看 | 再验证 |
|------|------|------|--------|
| 1 | 财政是在扩张还是收缩？ | ①-1、①-2 两本账各自的收支增速 | ①-3 赤字代理 |
| 2 | 收入压力来自哪里？ | ②-1 税收/非税 | ②-2 央地、②-3 税基 |
| 3 | 土地财政是否构成主要拖累？ | ②-4 地方基金与土地收入 | ①-1 全国基金收入增速 |
| 4 | 支出加力投向哪里？ | ③-2 民生、③-3 发展支出 | 与 ③-1 总支出比较，而非只看单项正负 |
| 5 | 财政空间是否被刚性负担侵蚀？ | ③-4 付息增速与付息占比 | 不外推隐性债务，等待债务融资维度 |

### 4.4 典型状态识别

| 状态 | 组合信号 | 结论边界 |
|------|----------|----------|
| 主动财政扩张 | 两账本支出增速加快；发展或民生支出同步改善；可观察赤字代理扩大 | 若扩大主要源于收入坍缩，要改判为被动缺口。 |
| 被动缺口扩大 | 两账本收入走弱；支出仅维持；可观察赤字代理扩大 | 不等同政策主动刺激。 |
| 土地财政拖累 | 土地出让、地方基金收入和全国基金收入增速持续偏弱 | 需与地产维度交叉，但不重复地产指标。 |
| 非税补位 | 税收弱、非税强，总收入勉强稳定 | 非税来源异质，不直接称财力质量改善。 |
| 付息挤压 | 付息增速高于总支出且付息占比上升 | 只描述预算内刚性约束。 |
| 央地执行分化 | 中央本级与地方支出增速明显分化 | 不将中央本级支出误作全部中央财政支出。 |
