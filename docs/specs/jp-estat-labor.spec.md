# 日本 e-Stat 劳动力调查接入

## 范围与复用门

2026-09-10 通过 e-Stat `getStatsList` / `getMetaInfo` / `getStatsData` 核验日本总务省统计局劳动调查 Basic Tabulation。本批接入 12 条未季调月度官方事实：就业人数、失业人数、劳动参与率、就业率，各含总计、男性、女性。

旧 `jpov_c21_unrate_sa` 是季调失业率，口径与本批不同，保留原事实和订阅。工资、实际工资、工时属于厚生劳动省每月勤劳统计，不在本批范围，后续单独核验表与样本范围。

## 官方表与固定维度

- 人数表 `0003005798`：`cdTab=01`、`cdCat01=000`（全行业）、`cdCat02=02/08`（就业/失业）、`cdCat03=0/1/2`（总计/男/女）、`cdArea=00000`（全国），API日文响应单位为“万人”。
- 比率表 `0003005865`：`cdTab=02`、其余维度相同，`cdCat02=01/13`（劳动参与率/就业率），API日文响应单位为全角“％”，数据库展示统一为ASCII `%`。
- 月度时间分类名由 `CLASS_INF` 解码；不能把10位分类代码截成日期。年度、季度及财政年度值不进入月度序列。

## 历史边界

本批明确从 2018-01 开始，共103个月至2026-07。官方metadata说明2018–2021已按最新人口基准回溯调整；更早Basic Tabulation与官方可比时间序列表存在基准差异，且2011年震灾期间有缺口。因此不把2000年以来原表直接包装成单一可比长序列。后续如接全历史，必须先找到官方Special Series并按人口基准分段审计。
