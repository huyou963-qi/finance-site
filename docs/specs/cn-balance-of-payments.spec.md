## §1 分析框架

### 1.1 核心问题（L0）

中国对外盈余是否健康且可持续：经常账户盈余主要来自货物竞争力，还是服务和收入项目收缩；盈余对应的资本流动是直接投资、证券投资还是银行及其他投资；外汇市场高频供求是否与季度国际收支一致；中国的净对外资产、储备资产和外债组合能否抵御外部融资与汇率冲击？

模板按以下顺序判断：

`经常账户与货物/服务来源 → 直接/证券/其他投资结构 → 结售汇与涉外收付款高频验证 → 净国际投资头寸与储备/外债缓冲`

本维度不把“顺差扩大”直接等同经济走强。货物顺差可能来自出口竞争力，也可能来自国内需求偏弱导致进口收缩；资本净流出可能是居民和企业正常增配海外资产，也可能反映风险偏好下降，必须结合项目结构、高频资金流和储备变化共同判断。

### 1.4 核心口径与结论纪律

| 口径 | 正确用法 | 禁止解释 |
|------|----------|----------|
| 国际收支交易流量 | 使用 BPM6 交易口径的季度差额，正负号按 SAFE 原表保留 | 不把国际投资头寸的季度变化当作当季国际收支流量；头寸还受汇率、价格和其他调整影响。 |
| 经常账户差额 | 正值为经常账户顺差，主图继续拆货物和服务；两者不能完全解释的部分包括初次收入和二次收入 | 顺差扩大不必然表示经济更强；进口和居民境外服务消费收缩也会扩大顺差。 |
| 金融账户分项 | 按“净获得金融资产－净发生负债”展示；正值表示对外净资产增加，即净资本流出/净贷出，负值表示净资本流入/净借入 | 不把正值误写成资本流入。直接、证券、其他投资与储备资产加总时还需考虑金融衍生品等小项。 |
| 银行结售汇差额 | 观察境内外汇市场结汇与购汇后的净供求 | 不是完整跨境资本流动，也不等于央行外汇占款或人民币汇率压力。 |
| 银行代客涉外收付款差额 | 观察居民和非银行企业跨境收支的高频净额 | 与 BOP 在主体、时点、分类和调整上不同，不要求逐月/逐季完全相等。 |
| 净国际投资头寸 | 正值表示对外资产高于对外负债，是存量偿付能力锚 | 净资产为正不表示不存在局部美元流动性、期限或部门错配。 |
| 储备资产/外债总额 | 作为广义外部缓冲比率，观察方向与数量级 | 不是 Guidotti–Greenspan 短期外债覆盖率；当前 SAFE 外债解析未保留可靠的总短期外债层级，不能冒充一年内到期债务覆盖。 |

最低结论纪律：

1. “外部平衡改善”至少需要经常账户来源质量、资本流动结构或高频资金流中的两类证据支持，不能只看单季顺差。
2. 货物顺差扩大但服务逆差收窄主要来自跨境活动下降、且进口偏弱，应写“货物项托底、国内需求偏弱”，不能写全面外部竞争力增强。
3. 证券和其他投资持续净流出、结售汇与涉外收付款同时转负，才可称跨境资金压力上升；仍需检查人民币汇率和境内外利差。
4. 净国际投资头寸为正、储备/外债比率较高只能说明总量缓冲，不消除银行、企业或期限错配风险。

## §4 图表介绍与分析方法

### 4.1 模板 description

- 模板 ①：在一套四图中依次判断经常账户盈余来源、非储备资本流动结构、月度跨境资金压力，以及净国际投资头寸和储备对外债的广义缓冲。

### 4.2 chartIntroNotes 草稿

**模板 ①**

1. 图 1：先看经常账户总差额，再用货物和服务差额解释主要来源。总差额与两项并不要求完全相等，差额还包含初次收入和二次收入；若货物顺差来自进口走弱，应跳转外贸和 Overview 检查国内需求。
2. 图 2：按 BPM6 原始符号比较直接、证券和其他投资。直接投资通常更稳定，证券和其他投资对风险偏好、利差和汇率预期更敏感；正值为净流出，负值为净流入。
3. 图 3：结售汇差额反映境内外汇买卖净供求，涉外收付款差额反映非银行部门跨境收支。两者同时转负且延续数月，才构成较强资金流出压力信号；短期背离先检查统计覆盖和企业留汇行为。
4. 图 4：净国际投资头寸看累积后的净债权地位，储备/外债比率看广义缓冲。比率上升表示缓冲增强，但不含期限结构，必须标注“非短期外债覆盖率”。

### 4.3 决策树（观察 → 对照图位 → 典型结论）

| 观察 | 对照图位 | 典型结论 |
|------|----------|----------|
| 经常账户顺差扩大，货物顺差扩大，服务差额稳定 | ①-1 | 外部盈余主要由货物项目改善驱动；再到外贸模板判断出口数量、价格和国别来源。 |
| 经常账户顺差扩大，但货物进口走弱、服务逆差因跨境活动下降而收窄 | ①-1 + Overview | 顺差扩大更多来自国内需求偏弱，而非外需全面增强。 |
| 经常账户顺差稳定，直接投资转为净流出，证券和其他投资波动不大 | ①-1/2 | 储蓄通过长期资本配置对外输出，暂不等同短期避险外流。 |
| 证券、其他投资净流出扩大，结售汇和涉外收付款同步转负 | ①-2/3 | 市场型跨境资金压力上升；需再查人民币汇率和境内外利差。 |
| 资本分项显示净流出，但结售汇平稳、涉外收付款为正 | ①-2/3 | 季度 BOP 与月度代理背离，可能来自覆盖差异、留汇、时点或修订，暂不下单向外流结论。 |
| 净国际投资头寸为正且上升，储备/外债比率稳定 | ①-4 | 中国总量外部偿付能力较强，但不能排除部门、币种或期限错配。 |
| 净国际投资头寸下降，储备/外债比率同时下行 | ①-4 | 外部资产负债表缓冲边际减弱，应提高对资本流动、汇率与美元融资条件的关注。 |

### 4.4 最终输出句式

结论按“经常账户状态—来源质量—资本流动结构—高频验证—外部缓冲”五段输出，例如：

> 经常账户继续保持顺差，主要由货物顺差扩大贡献，服务项目仍为逆差；非储备金融账户中直接投资较稳定，证券和其他投资净流出有所扩大。月度银行结售汇与代客涉外收付款尚未同步恶化，说明季度资本流出暂未形成全面外汇供求压力。净国际投资头寸保持正值，储备资产对外债总额的覆盖仍高，但比率边际下降。因此当前更接近“经常账户提供基本盘、市场型资本流动压力有所上升、总量外部缓冲仍充足”，而不是国际收支失衡。下一步应到外贸模板判断货物顺差来源，并到人民币市场条件专题核验汇率与利差。
