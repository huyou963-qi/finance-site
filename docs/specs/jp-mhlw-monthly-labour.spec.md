# 日本每月勤劳统计工资、工时与雇用核心序列 Spec

状态：`data-ready`

## 1. 范围和复用结论

本批接入日本厚生劳动省（MHLW）每月勤劳统计全国调查的六条基础指数。口径统一为：调查产业计、常用劳动者 5 人以上事业所、就业形态计、月频、未经季调、2020 年平均=100。

仓库内没有同口径 MHLW 序列。旧 e-Stat 数据库表（例如旧实质工资 DB view）只更新到 2021 年，不能作为现行订阅；本实现不会调用或拼接这些停更 API 表。劳动力调查的就业人数/失业率衡量居民端劳动供给，与本批企业端工资、工时和常用雇用指数不同，保留并存。

- 2026-09-12 实测 `statInfId`：表 1/7/19/25-2/29/41 分别为 `000032189714`、`000032189720`、`000032189732`、`000040277106`、`000032189742`、`000032189754`。

## 4. 解析、修订和失败边界

解析器只读取 `TL` 页第一段 `Indices`，拒绝第二段同比增长率。它逐项校验 5 人以上、就业形态计、调查产业计、2020 基期、12 个明确月列；缺页、改基期、错口径、重复年份、未知缺失标记、月度内部缺口、未来月份或异常值均终止本轮写库。

官方长期文件每月整表重发，历史可能修订。因此 adapter 每次返回 1990 年以来全量数据，由统一 canonical writer 跳过不变值并记录真实抓取时点发生的修订。本账本不能反推历史首发 PIT。

最新月“速報”文件每月有新的 `statInfId`，并且可能先于六张长期表更新。本批不把速報硬拼到长期确报序列，以免六项末期状态不一致。订阅的新鲜度按长期表自身最新观测判断。
