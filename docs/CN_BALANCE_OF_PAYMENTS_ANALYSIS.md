# 中国国际收支分析

> 本文档与 `cnBalanceOfPaymentsAnalysisLayout.ts`、`cn-balance-of-payments.spec.md` 和 `.cursor/prompts/cn-balance-of-payments-analysis-framework.md` 保持一致。

## 1. 核心问题与边界

本维度回答：中国经常账户盈余来自哪里，季度资本流动由哪类项目主导，月度跨境资金压力是否确认，以及净国际投资头寸和储备资产能否覆盖外债总额。

分析链条为：

`经常账户来源 → 直接/证券/其他投资 → 月度结售汇与跨境收付 → 净国际投资头寸与储备/外债缓冲`

本模板不重复海关贸易结构、人民币汇率、国内金融条件或 GDP 分析。国际收支货物口径不等同海关贸易差额；季度 BOP、月度资金流代理和季度头寸数据不能机械加总。

## 3. 口径纪律

- 经常账户正值为顺差，但货物和服务不能完整解释总差额，剩余部分包括初次收入和二次收入。
- BPM6 金融账户净额按“净获得金融资产减净发生负债”记录：正值表示净资本流出，负值表示净资本流入。
- 银行结售汇与代客涉外收付款是不同覆盖范围的月度代理；二者持续同向才构成较强验证。
- 净国际投资头寸是存量，变化同时受交易、价格、汇率和其他调整影响，不能当作当季资本流量。
- 储备/外债较高只表示总量缓冲，不能排除部门、币种或期限错配。
- 不把所有指标除以 GDP；本模板只计算有明确偿债含义的储备资产/外债比率。

## 4. 典型状态

| 组合信号 | 判断 | 后续复核 |
|----------|------|----------|
| 经常账户顺差扩大、货物项改善、服务稳定 | 外部盈余的货物来源增强 | 到外贸模板核验数量、价格和国别结构 |
| 顺差扩大但进口偏弱、服务逆差因跨境活动下降而收窄 | 盈余受国内需求偏弱影响 | 到 Overview 核验消费、投资与进口 |
| 证券与其他投资净流出扩大，两个月度差额持续转负 | 市场型跨境资金压力上升 | 核验人民币汇率与境内外利差 |
| 季度资本净流出但月度差额平稳 | 统计覆盖、留汇、时点或修订可能导致背离 | 暂不下“全面流出”结论 |
| 净国际投资头寸为正、覆盖率稳定 | 总量外部偿付缓冲较强 | 仍需检查短债、币种和部门错配 |
| 净头寸与覆盖率同步下降 | 外部资产负债表缓冲边际减弱 | 提高对资本流动和美元融资的关注 |

## 5. 数据与调度

所有 11 条原始序列均来自既有 `safe-external` 数据源。月度资金流、BOP、IIP、外债分别归入：

- `cn.safe.external`
- `cn.safe.bop-quarterly`
- `cn.safe.iip-quarterly`
- `cn.safe.external-debt-quarterly`

BOP 解析使用 SAFE 季度美元表的稳定语义 code；2026-08-11 仅针对此前缺失的 `bop` dataset 回填历史。结售汇、涉外收付款、IIP 和外债沿用数据库既有观测，没有重新抓取。

专项自检：

```bash
npm run data:verify-cn-balance-of-payments -- --db
npm run data:verify-safe-external -- --db
```

## 7. 每期检查清单

- [ ] 经常账户变化由货物、服务还是收入项目残差驱动
- [ ] 金融账户正负号是否按 BPM6 正确解释
- [ ] 直接投资与证券/其他投资的稳定性是否分开判断
- [ ] 两个月度资金流代理是否连续、同向确认
- [ ] 是否把 BOP 流量与 IIP 头寸混为一谈
- [ ] 储备/外债是否被误称为短期外债覆盖率
- [ ] 是否越界把顺差扩大写成全面经济走强
