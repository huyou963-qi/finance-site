# 中国财政分析框架

本文档与宏观页内置模板、`cnFiscalAnalysisLayout.ts`、`.cursor/prompts/cn-fiscal-analysis-framework.md` 保持一致。

## 阅读顺序

1. 打开「财政全景」，比较一般公共预算与政府性基金预算各自的收支累计同比。
2. 查看两本账各自及合并可观察赤字代理，再用年度 GDP 标准化合并代理。
3. 收入承压时打开「财政收入」，定位税收/非税、央地收入、主要税基与土地财力。
4. 支出加力时打开「财政支出」，定位央地执行、民生、发展支出与付息约束。

## 核心口径

- 一般公共预算和政府性基金预算属于中国“四本预算”中的前两本；本框架不等于四本预算合并财政。
- 月度财政金额与同比均为当年累计口径，不倒推官方未发布的单月值或环比。
- 赤字代理定义为“累计支出−累计收入”，正值表示支出高于收入。
- 两账本合并可观察赤字代理未处理调入调出、结转结余及账间重复，不等于官方赤字、广义财政赤字或融资需求。
- 赤字/GDP只使用12月累计值和同年年度名义GDP；未完成年度不出值。
- 地方本级收入不含中央转移支付，不能与地方支出直接相减。
- 中央本级支出不等于中央财政全部支出；转移支付形成的支出主要体现于地方执行。

## 数据与运维

```powershell
npm run data:verify -- --catalog=mof-fiscal -- --db
npm run data:verify -- --catalog=nbs-gdp -- --db
```

原始数据均来自既有财政部与国家统计局订阅；赤字代理及比例由宏观页展示层链式派生，不新增原始 `Instrument` 或观测。

## 当前覆盖边界

暂不包括官方预算/决算赤字率、国债与地方债发行余额、转移支付明细、国有资本经营预算、社会保险基金预算及隐性债务。这些指标不得由当前两本账机械外推。
