# Pro AI 数据连接

用户在支持远程 MCP 和 OAuth 的客户端连接 `/api/mcp`，通过 GekkoTech 账号同意只读权限 `research:read`。在「工具 → AI 数据连接」可查看用量和撤销授权。用户的多个客户端共用账号额度。

客户入口在功能权限中默认开发中。最高管理员可试用，客户使用需要管理员确认发布并在功能权限中设为已上线。后端按有效 Pro 套餐判定，注册试用和回测积分不计入资格。当前资格沿用站内 Pro 权益字段，因此管理员明确授予的有效 Pro 套餐也符合资格。

| 工具 | 能力 |
| --- | --- |
| `get_usage` | 查看当月额度和重置时间 |
| `search_market_indicators`、`query_macro_data` | 查找指标并读取原生频率时间序列，历史可见模式沿用版本证据 |
| `calculate_macro_series` | 口径校验与白名单计算。同比自动读取请求区间之外所需的上年基期，仅返回请求区间的数据；月频按上年同月，其他频率按上年同日。缺失与为零的基期分别列出。 |
| `search_system_charts` | 搜索系统图表并返回站内链接。「美国住房」可找到住房供需图。住房开工和许可标明单户或总量口径；指标搜索缺少指定范围时会提示可另查的不同口径。 |
| `search_securities`、`search_stock_indicators` | 搜索已入库证券和可调用指标 |
| `query_stock_data` | 查询最多 10 只美股与 20 列指标，按需返回实际报告期、日期及缺失状态 |
| `query_stock_quarterly_financials` | 一只美股按财季末日期区间读取至多 12 个报表科目。返回单季值、财季末、已知的财年季别和缺失指标；区间最多 15 年。 |
| `compare_stock_macro_quarters` | 将至多四条周频或月频宏观指标按一只美股的实际财季聚合。返回原始季均值、变换值、窗口、领先期、有效配对数与 Pearson 相关系数。 |

股票调用复用股票数据页的指标目录和计算服务，仅读取已入库数据。交易所字段依赖外部证券目录，首批未开放。股票历史报告期查询可能含后续修订。新建的数据表保存账号月用量和临时调用租约，底层数据由原有调度维护。客户返回使用独立的公开字段映射。

每账号滚动一分钟 20 次、同时 2 个查询。全站默认同时 4 个查询，默认每账号每 UTC 自然月 1,000 点会员额度，和网页回测、稳健性分析共用。每次网页任务扣 1 点。短时并发和频率限制只针对 AI 调用。查询按指标数、时间范围和计算规模预扣额度，已开始执行的调用计量包括空结果和执行失败。用量查询不扣点，仍受频率及并发限制。短时限流、并发租约和月用量事务由同一 PostgreSQL 实例在多个进程间共享。

批量股票工具的单季毛利率与季度财务查询使用同一取值逻辑，均返回 `grossMarginSource`。两者优先保留已有毛利率，来源标记为 `stored`，入库值可能已由财报科目计算。缺失时，只用同季同口径的毛利润与营收，或营业成本与营收计算，返回相应的 `grossMarginSource`。季度对齐使用最新可得观测，保留聚合口径和配对缺口，要求同时具备宏观和股票数据功能权限。

限流和额度错误保留原有 `code`，增加 `reason`、`retryAfterSeconds` 和 `retryAt`。并发等待值为建议退避时间。额度拒绝返回剩余点数、请求所需点数及重置时间；单次请求超过月上限时，重试时间为空，需缩小查询。

部署时执行现有 `npm run db:migrate`，并设置 `APP_BASE_URL` 及 `RESEARCH_MCP_OAUTH_CLIENTS`，后者填写客户端 ID 和平台实际提供的完整 HTTPS 回调地址。沿用已登记客户端的 OAuth 授权码流程，使用 PKCE S256。客户与管理员文章 OAuth 资源分开，凭证相互隔离。

上线验收覆盖实际目标客户端的 OAuth 往返、宏观查询、股票取数、额度扣减、撤销与到期。先用管理员验收客户端与回调配置，再在获准发布后对有效 Pro 账号开启。

## 第二阶段工具

| 工具 | 能力和边界 |
| --- | --- |
| `get_stock_disclosures`、`get_stock_guidance` | 单只股票的近期申报、官方链接与管理层指引证据。指引最多检查 24 份入库公告。 |
| `get_stock_disclosure_archive` | 用公告编号和附件名称分页读取站内已归档公告文字。多附件时先选附件，有缺档时明确返回状态。申报事件日期与附件内的财报期可能不同。 |
| `get_stock_insider_filings` | 最多 20 条 Form 4 及其修订的申报引用。 |
| `compare_industries` | 最多 3 个板块 ETF、12 个季度，支持单季或 TTM、当前成分或历史持仓。返回财务汇总及权重覆盖率。 |
| `search_research`、`get_research` | 按类型检索及分页读取已发布文章、周报、公开事件。每页正文最多约 12,000 字符。 |
| `list_screener_factors`、`screen_stocks` | 使用单期既有因子截面，最多 5 个筛选条件、1 个排序因子、30 条结果。附实际截面日期和缺失因子统计。 |
| `get_forecast_summary` | 返回已开放的美国 CPI、非农、GDP 预测摘要。仅使用站内观测和版本数据，结果缓存 30 分钟。同一次冷查询合并。 |

按各功能现有开放策略决定工具及参数是否出现在发现列表。研究文章和事件按其公开状态过滤，周报沿用连接的有效 Pro 权限。管理员可验收开发中的预测。工具复用原有计算、目录和数据表，沿用第一阶段 OAuth 资源、用量和限流。客户端需刷新工具列表以发现第二阶段功能。

## 第三阶段首批工具

| 工具 | 权限及用途 |
| --- | --- |
| `get_my_watchlist` | 个人读取。分页读取本人自选股，可指定已有分组。 |
| `list_my_stock_templates`、`get_my_stock_template` | 个人读取。查看本人保存的股票数据模板及可传给取数工具的列参数。 |
| `add_to_my_watchlist` | 个人写入。一次添加最多 10 只站内已登记美股。已存在的标的保留原分组。 |
| `save_my_stock_template` | 个人写入。另存新的股票数据模板。相同名称及内容可重试，同名不同内容需要换名。 |

基础权限仍为 `research:read`。客户端可额外请求 `research:personal:read` 或 `research:personal:write`，用户在授权页分别勾选。已有连接可继续读取研究数据，增加个人权限时需重新授权。连接管理页会显示每个授权实际拥有的权限。

股票模板与「股票数据」页面同步，自选与「行情」页面同步。访问范围取自 OAuth 所属账号，写入沿用同一份数据和共享额度。模板可保存网站允许的最多 50 列与 50 只股票，实际 AI 取数仍按现有每次 20 列、10 只股票分批。

## 同业、事件行情与图表

以下工具使用基础 `research:read`，分别遵循网站的行情、个股或宏观功能权限。

| 工具 | 能力 |
| --- | --- |
| `compare_stock_peers` | 自动找最多 10 只当前站内同业，优先使用 GICS 子行业，排除目标股。返回最新的估值和利润率、相同端点的前复权收益、等权同业收益、SPY 和缺失覆盖。 |
| `get_stock_event_returns` | 读取最多 20 次站内财报业绩稿、财报申报、8-K 或拆股事件，计算之后 1 至 10 个交易日的前复权收益。核验为盘前时可计当天，盘中或日期精度不足时从下一交易日开始。行情不足的窗口明确标注。 |
| `get_system_chart_data` | 使用 `search_system_charts` 返回的 `chartId` 读取支持的系统图表，返回日期、变换后的序列、单位和来源。同比会使用区间前的上年观测，可指定历史可见截止时间。 |
| `render_stock_chart_png` | 使用已入库的美股行情生成日、周或月 K 线及成交量图，可选复权和财报标记。MCP 返回原始 `image/png`、资源引用，以及同一份 PNG 的 `imageUrl` 与 `downloadUrl`。链接 24 小时内有效。 |
| `render_stock_event_pack_chart` | 外部 AI 通过客户端搜索核实公开事件，按 v2 事件包结构提交 `eventPack`。服务端复用行情页事件校验和显示范围规则，直接生成带编号标记的美股 K 线 PNG、编号和真实日期对照、未上图原因以及可导入的 JSON。仅日期事件按记录日期定位，带时区事件按 UTC 日定位。非交易日对齐到区间内下一根完整交易日。PNG 和 JSON 链接有效期为 24 小时，持链接者可读取。事件包用于临时预览，不写入共享事件库或浏览器事件收藏。 |

## 量化研究、持股监控与个人模板

| 工具 | 能力 |
| --- | --- |
| `get_macro_regime` | 查询站内当前的月度宏观环境和实时市场定价摘要，或按日期区间读取已保存的月度记录。 |
| `get_factor_research_summary` | 按站内月度截面研究最多 4 个因子、5 年历史。提供 IC、分层收益、IC 衰减、按宏观环境汇总的 IC 和因子相关矩阵。 |
| `list_my_quant_reports`、`get_my_quant_report` | 查看本人已完成的回测与稳健性报告。回测提供净值和调仓期宏观状态，稳健性报告提供已有的参数扫描、样本外或滚动检验结果。详情可分页。 |
| `get_stock_ownership_monitor` | 读取已核实的内部人买卖、按证券类别区分的 90 日净卖出统计，以及有证据支持的 10b5-1 计划。覆盖不足时比率或计划剩余额度为空。历史结果依据当前核实的披露重建。`resultSummary` 区分同步覆盖、已核实匹配数和本页行数。`form4Coverage` 按请求区间申报日统计站内 Form 4/4-A 索引、v2 结构化文档及可由该标的读取的文档。 |
| `get_my_macro_templates`、`get_my_screener_strategies` | 不带 ID 时列出本人保存的宏观模板或选股策略；提供 ID 时读取指标配置或筛选条件。 |

本人报告、宏观模板和策略使用可选权限 `research:workspace:read`。用户通过授权页勾选后可使用，新权限不会加入旧授权。工具发现和执行检查对应的网站功能权限。此批工具均为只读，回测任务在网站提交。
