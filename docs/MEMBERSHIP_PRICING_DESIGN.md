# 会员与订单管理设计版

入口：账户菜单 → 会员与订单（/admin/orders）。

## 本版

- 套餐设置：月付、季付、年付价格、展示开关、展示文案。
- 营销折扣：百分比减免、固定直减，按首次付费/续费人群、套餐、北京时间日期匹配；不叠加。
- 下单试算：按今天北京时间实时计算资格和金额，隐藏套餐明确提示不可购买。
- 浏览器草稿：显式保存及载入，不修改服务端配置；季付 109 元仅为设计建议。
- 订单管理：复用真实订单列表、收款核验、密码/TOTP 与审计流程。
- 双端：同一导航与控件，小屏套餐纵排、表单单列，订单保留既有移动卡片。

## 正式接入边界

当前后端仅支持 pro_month/pro_year/credits，定价来自 src/lib/billing/pricing.ts。本版是可交互设计，不会改变结算与权益。

后续正式实现应复用既有 billing orders/fulfillment 服务，增加套餐及活动配置唯一事实源；创建订单时服务端计算并保存套餐版本、原价、优惠规则、实付和权益期限快照。支付查单及回调校验订单快照金额，禁止读取现价重新计算历史订单。季付须贯通订单类型、支付校验、权益发放、对账与统计。配置发布须沿用后台权限、密码/TOTP、变更原因及审计，会员运营与订单处理岗位分别授权。零元订单需独立设计受审计的发放流程。当前为一次性购买，不表示自动续订。

## 订单确认融合

默认打开订单管理，统一展示自动支付与历史人工收款。支持在最近 200 笔真实记录内按状态、收款方式、订单号/用户/邮箱/流水过滤，统计明确限定为这些记录。分别展示支付时间及权益发放时间，避免把支付成功等同于权益已发放。平台查单完成后刷新列表，保留支付跟踪；人工确认仅从待支付的非 ZPAY 订单发起，原服务端权限、凭据及审计检查保持不变。桌面表格与手机卡片提供相同操作。
