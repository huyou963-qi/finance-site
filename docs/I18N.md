# 界面多语言（中文 / English）

## 现状（阶段 0 已完成）

英文版面向**海外用户**，所以语言由**网址**决定，搜索引擎能分别收录中英文页面：

| 网址 | 语言 |
|------|------|
| `/macro`、`/`（不带前缀） | 中文（默认） |
| `/en/macro`、`/en` | English |

- 框架：`next-intl`（不分路由模式）。`src/middleware.ts` 把 `/en/...` 内部转到同一个页面，并通过请求头
  （`x-app-locale`、`x-app-pathname`）告诉服务端语言和去掉前缀的路径。**页面文件不用挪进 `[locale]` 目录。**
- 英文文案与中文深合并，**英文缺的键显示中文**，所以可以一页一页地翻，不会出现空白。
- 记住偏好：进入 `/en/...` 时写 cookie `NEXT_LOCALE=en`；之后打开不带前缀的页面会 307 到对应 `/en` 页面，
  所以还没改成本地化链接的跳转（`router.push("/x")`、`window.location` 等）也留在英文。切回中文走
  `/api/i18n/reset?to=...`，清 cookie 再跳中文页。
- 开关：功能目录里的 `site-language-en`（`kind: "setting"`，分组「站点」），默认 **开发中**。
  - 切换入口：电脑版顶栏右侧、手机版导航抽屉底部「Language/语言」，都经 `useVisibleFeatures().can("site-language-en")` 过滤。
  - 服务端兜底：没开放英文的身份打开 `/en/...`，根布局经 `/api/i18n/reset` 送回中文页（不会重定向循环）。
  - 上线：管理员在 `/admin/feature-access` 把「英文界面」切到已上线。**用户确认前不要上线。**
- SEO：英文**已上线后**，根布局才输出 `hreflang`（zh-CN / en / x-default）与 canonical；`robots.txt` 同时屏蔽
  `/admin` 与 `/en/admin` 等私有路径。
- 根布局按请求读请求头，原来静态预渲染的登录、定价、后台等页面改为按请求渲染（其余页面本来就是动态的）。

## 站内链接怎么写

- 用 `@/i18n/navigation` 的 `Link`（自动加当前语言前缀），不要直接用 `next/link`。
- 判断当前页面用 `useLocalePathname()`（中英文得到同一个路径），不要直接用 `usePathname()`。
- 其他拼地址的地方用 `localizeHref(href, locale)`。
- 页面自设 `alternates.canonical` 会覆盖根布局的 hreflang：翻译这类页面时要改成按语言输出
  （目前有 `/articles/[slug]`、`/equity/industries`、`/equity/sectors/*`、`/equity/stocks/[symbol]`）。

## 代码位置

| 文件 | 作用 |
|------|------|
| `src/i18n/locales.ts` | 语言列表、cookie 名、深合并等纯函数 |
| `src/middleware.ts` | `/en` 前缀转发、记住英文偏好 |
| `src/i18n/server.ts` | 服务端取本次请求语言（含权限兜底）、英文是否已公开 |
| `src/i18n/request.ts` | next-intl 每个请求的文案 |
| `src/i18n/navigation.tsx` | 本地化 `Link`、`useLocalePathname` |
| `src/app/api/i18n/reset/route.ts` | 清英文偏好并回中文页 |
| `src/i18n/messages/zh.json` | 中文文案，**键名的唯一来源** |
| `src/i18n/messages/en.json` | 英文文案，只能有 zh.json 里已有的键 |
| `src/i18n/next-intl.d.ts` | 按 zh.json 做键名类型检查 |
| `src/components/LanguageSwitcher.tsx` | 中文 / English 切换 |
| `src/lib/i18n/format.ts` | 按语言格式化数字（中文 万/亿，英文 K/M/B）与日期 |
| `src/i18n/messages.test.ts` | 键对齐检查 + 已翻译文件不得含硬编码中文 |

## 翻译一个文件的步骤

1. 把界面文字移到 `zh.json`（按模块分命名空间，如 `nav`、`auth`、`pricing`），在 `en.json` 写对应英文。
2. 客户端组件用 `useTranslations("ns")`；服务端组件用 `getTranslations("ns")`（`next-intl/server`）。
3. 数字、日期用 `src/lib/i18n/format.ts`，不要手写「亿/万」。
4. 把该文件加进 `src/i18n/messages.test.ts` 的 `TRANSLATED_FILES`，防止以后又写回中文。
5. 电脑版和手机版都检查一遍（英文通常更长，注意换行和截断）。

不翻：数据管线（`src/lib/data/scheduler` 等）、后台 `/admin`、日志与错误上报里的内部文案。
