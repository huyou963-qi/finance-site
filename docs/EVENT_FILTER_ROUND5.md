# 第 5 轮：本地事件与简洁设置

日期：2026-10-29。按用户要求取消用户事件云同步，简化系统事件、用户事件的设置。基于最新主线 6741634，保留其他同期发布的衰退阴影等改动。

## 修改

- 用户事件只在当前浏览器保存，继续按账号分区，保留旧本地包、包 ID、事件 ID、重导开关/配色和旧偏好迁移。
- 删除云端事件 hook、30 秒轮询、凭证管理组件、投递解析与数据库 writer 及其专用测试。旧读写/凭证端点直接返回 410，不读取请求体、不认证、不访问数据库，避免旧客户端继续写入。
- 已发布的两张云端表和 migration 保留，不做破坏性删除；没有新 schema/migration。不能把停止新增数据描述为清空历史存储。
- 更新 Skill、使用说明和 ZIP。生成本地 JSON 后导入；不再索要凭证、环境密钥或提供云投递。旧协议 URL 覆盖为停用说明，确保部署覆盖后不残留旧指引。
- 左侧系统/用户分页保留，面板仍为 180px。常用操作一行：桌面搜索、筛选、清除、K 线显示、设置和条数；用户页直接增加导入。手机搜索放入筛选弹窗，常用按钮在 320px 仍可同时显示。
- 将来源管理、图表显示合并为一个「设置」入口。来源/本地文件和显示方式默认可见；关联范围、导入覆盖范围、类型配色和单条标记控制默认折叠。文件默认只展示开关、名称、条数、范围和导出，颜色/删除放入文件选项。
- 统一桌面/手机的草稿筛选弹窗，取消不应用；生效条件可在弹窗查看、删除。工具栏保留已选提示，桌面提供直接清除。
- 导入预览默认只显示包名、新增/更新/未变、范围和开关，包 ID、跨包冲突及保留记录放入折叠明细。结果默认去除包 ID 等实现细节，继续解释不可见原因。成功导入不再额外增加一条固定状态行。

## 验证

浏览器专项使用实际组件、实际本地存储 hook 与固定 API 夹具，覆盖 1280、390、320px：

- 单行日常操作、一个设置入口、直接导入与取消、旧本地包加载和导出入口；没有凭证界面。
- 定时器前进 65 秒和窗口重新聚焦后，云端事件 API 请求数为零。
- 搜索/筛选相互独立，取消草稿不写入，关闭上图保留列表；筛选类型和宏观条件可恢复。
- 跨包同 ID 不丢失、不误合并；同包新增/更新/未变和未提交记录保留，重导保持配色/开关，预览期间切换资产不改变导入范围。
- 模拟 localStorage 配额失败，原数据不变，恢复后可重试；首次账号确认失败时不写匿名分区，可显式重试。
- 系统事件加载失败保留用户事件、分页重复去重、切换标的清理旧结果。
- 三种屏宽无横向溢出或脚本错误，默认高度 180px；导入结果与本地设置有截图。

旧 API 的四种处理函数有 410 回归检查，无数据库依赖。`npm run verify:commit` 已通过：1281 项单元/架构测试、schema 校验、lint 和生产构建；浏览器专项全部通过，包含导出内容与删除备份核对。结果与截图见本地验证产物 `.data/verification/event-filter-round5/`。

本轮通过 PR 审查后再部署。只有发布本次改动后，生产环境才会停用云同步接口；本地验证完成不等于线上已经停用。发布状态以 PR 和部署记录为准。
