# 个股基本面：终端级能力缺口与数据源拍板

本文对应评估路线 **阶段 C**。下列能力需先选定数据源与成本后再开发；已落地项见「现状摘要」。

## 现状摘要（2026-11 更新）

| 已有 | 缺口 |
|------|------|
| SEC 标准化三表 **143+ 科目**（含 EBITDA 标签位、利息费用、流动资产等）+ TTM/估值/同业/事件 | 一致预期修订、Surprise、#analysts 的深历史 |
| Forward PE（估计接口，概览卡 + 行情叠加） | 分部收入/地区 |
| 13F → 因子层；持股监控 Tier A Form 4；DERA Tier B 全市场底座；股票数据页内部人列（股数口径） | 金额口径内部人（受 `price_check` 覆盖限制） |
| `ShortInterest` 表存在 | FINRA 源不可用 → 覆盖≈0 |
| 「股票数据」`/equity/data`：P0–P3 查询层（含技术指标、结果过滤、点格时序） | — |
