# 事件筛选第 3 轮：导入可靠性与本次结果

日期：2026-10-28。基于已发布的 `7809f38`，本轮在本地实现并验证，尚未提交或部署。沿用左侧来源分页和 180px 默认高度。

## 本轮目标与基线

让用户知道导入的目标包、实际显示范围、哪些记录新增或更新，以及导入后为什么看不到。保持原有筛选、停用状态和配色，不用修改用户条件来制造可见结果。

回放生产基线版本的本地包加载 hook：两个包共 4 条记录，其中两条使用相同 externalId；旧实现只加载 3 条。原因是跨包使用 externalId 作为 Map 键。其他发现包括：预览把所有包 ID 混在一起统计、重导自动启用包并覆盖缺省配色、导入时会清理其他 legacy 包的同 ID 节点。

## 实现

- 新增统一的包导入规划函数，预览与确认共用。只按目标包内的 ID 更新，未提交记录和其他包均保留，不再自动清理 legacy 包。
- 回执区分新增、内容更新、未变、原有未提交记录保留；提示其他包中出现的同 ID 不会被覆盖。确认操作读取最新本地存储重新计算，回执不是预览数字的直接复用。
- 同包重导保留 enabled、未指定的 color/version/name；明确指定的文件元数据仍可更新。重复导入相同记录不会生成新的事实节点。
- 本地展示身份改为 `(packId, externalId)`。原始 externalId 与原始事实记录保留，导出仍沿用既有协议。不同包的卡片、颜色和隐藏标记设置分别定位。
- 主图去重不再把不同用户包的相同 externalId 当作充分证据；仍可根据一致日期、类型、资产及来源/标题证据合并同一事实。来源列表保留每个包的记录；跨来源稳定 ID 的既有私人注释覆盖规则保留。
- 旧个人颜色、隐藏事件和隐藏标记偏好复制到对应包的独立键；已有独立覆盖优先，系统来源偏好不变。首次迁移备份到 `event-view-filters-v1-before-pack-ids`，原包数据不改写；重复迁移无变化。
- “按文件设置”正确使用 pack.symbols 或 query.symbol；手动选择当前资产或全部资产时按用户选择处理。预览展示真正将使用的范围与包开关，并冻结该范围；预览期间行情资产发生变化也不会把事件导入到另一个资产。
- 增加“本次导入结果”浮层，确认成功自动打开，关闭后可从用户页工具栏重新进入。只列出本次提交，展示当前可见数量及停用、范围、时间、内容条件造成的未显示原因；可见记录复用实际主图投影状态，不另算一套上图结果。
- 本次结果不改写筛选或开关，且仅保存在当前页面会话中；页面刷新后不提供历史批次账本。
- 保存失败保留预览并显示错误，不关闭预览或生成成功回执；浏览器存储失败时原值保留，可重试。无效 JSON 在事件包管理弹窗内显示。
- 修复旧文件只提供 id 时，多个有效事件被错误当作 externalId=undefined 重复的解析问题。

## 验证循环

1. 回放旧加载实现得到 3 条，确认跨包丢失；新版本加载 4 条、展示身份互不冲突。
2. 同包提交更新一条、保留不变一条、新增一条，验证回执为新增 1 / 更新 1 / 未变 1，未提交旧记录保留 1；另一包同 ID 未改动。
3. 停用的包重导仍停用，默认配色保留；本次结果先解释停用，启用后解释搜索不匹配，清除内容条件后显示可见 3 条。
4. 同文件重导显示新增 0 / 更新 0 / 未变 3；模拟浏览器存储配额失败，预览显示错误、无成功回执、存储原值不变，恢复后可确认。
5. 模拟预览打开后本地存储改变，确认回执按最新存储计算，不沿用旧预览数字；同包文件改名且未指定包名时，原包名保留；预览期间切换行情资产，确认仍使用预览范围并解释当前资产下的不可见原因。
6. 1280px、390px、320px 下复核导入预览和本次结果；关闭浮层后面板仍为 180px，切换资产立即按包范围过滤，无页面横向溢出。
7. 确认旧颜色与隐藏设置迁移、包身份键隔离、ID-only 兼容输入、区间外与内容排除原因，检查来源列表和主图去重不回归。

验收脚本使用真实包存储 hook、实际 UI 组件与浏览器 localStorage，认证与事件 API 使用固定本地夹具。无效 JSON 的断言等待异步文件读取完成后再检查提示，避免把尚未完成的读取误判为失败。
