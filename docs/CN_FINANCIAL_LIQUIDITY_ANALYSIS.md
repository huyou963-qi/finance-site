# 中国金融条件与流动性分析

> 本文档与宏观页内置模板、`cnFinancialLiquidityAnalysisLayout.ts`、`.cursor/prompts/cn-financial-liquidity-analysis-framework.md` 保持一致。

## 1. 核心问题与边界

本维度回答：中国金融条件是在放松还是收紧，流动性是否从贷款报价和银行间资金市场传到货币活性与实体信用，社融改善来自银行贷款、政府债券还是企业直接融资？

分析链条为：

`贷款定价与银行间资金价格 → 货币活性 → 信用总量 → 银行存贷扩张 → 融资结构`

v1 覆盖银行体系与信用传导，不是完整市场型 FCI。当前不包含央行公开市场操作、DR007/R007、国债收益率曲线、信用债利差、人民币汇率或权益风险定价，因此不得发布“综合中国金融条件指数”。

## 2. 分析层级

| 层级 | 问题 | 指标 | 模板/图 |
|------|------|------|---------|
| L0 综合判断 | 价格、货币活性和信用是否共同放松/收紧？ | LPR、银行间利率、M1/M2、社融与贷款同比 | ① + ②-1 |
| L1 贷款定价 | 短期与中长期贷款报价锚是否下调？ | 1 年期、5 年以上 LPR | ①-1 |
| L1 银行间流动性 | 有担保/无担保资金价格与价差如何变化？ | 质押式回购、同业拆借月均利率及差值 | ①-2 |
| L1 货币活性 | 广义货币是否转为交易性资金？ | M1、M2 同比及 M1−M2 | ①-3、①-4 |
| L1 信用总量 | 社融与银行贷款是否企稳扩张？ | 社融存量、人民币贷款余额同比 | ②-1 |
| L2 银行资产负债 | 信用扩张相对存款增长是否加快？ | 存款同比、贷款−存款增速差 | ②-2 |
| L2 融资结构 | 政府、银行和资本市场谁在支持社融？ | 银行贷款、政府债券、企业债券、股票融资占比 | ②-3、②-4 |

| 4 | 货币活化增速差 | 图 3 两条原始序列作为输入 | `calc:cn-financial-m1-m2-gap` | 柱状，左轴与零线 |

阅读顺序：

1. LPR 同步下调只说明贷款报价锚放松，不能单独确认实际融资成本下降。
2. 银行间两类月均资金价格同降，说明资金面大方向趋松；无担保−有担保价差扩大只作风险溢价代理。
3. M2 强而 M1 弱意味着总量流动性未充分进入交易性资金。
4. M1−M2 负差收窄或转正是货币活性改善信号，但受 M1 统计口径和结构影响，必须由信用模板确认。

### 模板 ②：信用扩张与融资结构

| 图 | 标题 | 原始序列 | 派生序列 | 图型/轴 |
|----|------|----------|----------|---------|
| 1 | 社融与银行信用增速 | `mds:pbc_cn_social_financing_stock_yoy`、`mds:pbc_cn_rmb_loan_yoy` | — | 折线，左轴 |
| 2 | 存款增长与贷存增速差 | `mds:pbc_cn_rmb_deposit_yoy`；贷款同比作为派生输入 | `calc:cn-financial-loan-deposit-growth-gap` | 存款折线左轴、差值柱右轴 |
| 3 | 银行信贷与政府融资占比 | `mds:pbc_cn_social_financing_cumulative`、`mds:pbc_cn_social_financing_rmb_loan_cumulative`、`mds:pbc_cn_government_bond_financing_cumulative` | `calc:cn-financial-tsf-rmb-loan-share`、`calc:cn-financial-tsf-government-bond-share` | 折线，左轴 |
| 4 | 企业直接融资占比 | 总社融累计与 `mds:pbc_cn_corporate_bond_financing_cumulative`、`mds:pbc_cn_domestic_equity_financing_cumulative` | `calc:cn-financial-tsf-corporate-bond-share`、`calc:cn-financial-tsf-equity-share` | 折线，左轴 |

阅读顺序：

1. 社融和贷款同比同步回升，才是较广泛的信用扩张；只有社融回升要继续看结构。
2. 贷款−存款增速差不是存贷比或流动性覆盖率，只描述银行资产与负债增速的相对变化。
3. 政府债券占比上升、贷款同比仍弱，应判断为政府融资托底而非私人信用复苏。
4. 企业债券和股票融资占比共同改善，才说明直接融资渠道接力。

## 4. 计算与时间轴规则

所有原始序列都是人民银行已入库的月频官方口径；DB 不保存以下派生值。

| 派生角色 | 公式 | 规则 |
|----------|------|------|
| 无担保−有担保资金价差 | 同业拆借月均利率−质押式回购月均利率 | 只在共同月份计算，单位百分点 |
| M1−M2 增速差 | M1 同比−M2 同比 | 单位百分点；标注 M1 口径结构断点 |
| 贷款−存款增速差 | 人民币贷款余额同比−人民币存款余额同比 | 单位百分点，不解释为存贷比 |
| 四类融资占比 | 对应年内累计分项÷社融增量累计×100 | 分母为 0/缺失则空；允许负值和 >100% |

社融增量与分项均为年内累计：每年 1 月重置，跨年折点没有环比含义；不同年份比较应优先比较相同月份。四个展示渠道并不穷尽全部社融分项，禁止堆叠成完整 100%。

## 5. 典型状态与决策树

| 组合信号 | 结论 | 边界 |
|----------|------|------|
| LPR↓、银行间利率↓、M1−M2 改善、社融/贷款同比↑ | 金融条件较完整地放松 | 仍不代表债券、汇率和权益市场均放松 |
| LPR↓，但 M1−M2 与信用同比继续下降 | 政策定价放松、传导偏弱 | 不称信用周期反转 |
| M2 强、M1 弱、贷款同比下降 | 总量充裕但资金活性与信用需求偏弱 | “资金淤积”是描述性判断 |
| 社融↑、贷款弱、政府债券占比↑ | 政府融资托底 | 对照中国财政模板，不称私人信用复苏 |
| 社融/贷款↑，银行贷款和直接融资占比改善 | 信用扩张更广泛 | 继续用增长模板验证实体结果 |
| 银行间利率↑、无担保价差↑、贷存增速差↑ | 银行体系资金来源相对承压 | 月均数据不能刻画短期尖峰或单家银行风险 |

## 6. 结论输出模板

按“立场—传导—结构—边界”输出：

> 贷款报价与银行间资金价格边际放松；M1−M2 负差收窄，货币活性有所改善；但社融企稳主要由政府债券占比上升驱动，人民币贷款同比仍弱，因此当前更接近“流动性宽松、私人信用传导有限”，而非全面信用扩张。由于缺少国债曲线、信用利差和汇率风险定价，本结论仅覆盖银行体系与信用传导，不代表完整市场 FCI。

## 7. 每期检查清单

- [ ] LPR 的 1 年期和 5 年以上方向、幅度是否一致
- [ ] 同业拆借和质押式回购月均利率是否同向，价差是否扩大
- [ ] M1、M2 同比与 M1−M2 的方向是否一致
- [ ] 社融存量和人民币贷款同比是否同步转向
- [ ] 贷款−存款增速差是否与银行间资金价格共振
- [ ] 社融改善来自人民币贷款、政府债券还是企业直接融资
- [ ] 是否把年内累计占比的 1 月重置误判为趋势拐点
- [ ] 是否越界声称完整 FCI、实际融资成本或私人需求复苏
