# 美国宏观事件区间研究 · 第一批实现

## 使用

行情页选择黄金、美元、美债或美国股指，展开底部「事件筛选器」，点击「宏观研究」。沿用现有行情时间轴范围，查看当前资产关联与筛选下的美国宏观、政策、官方讲话及异动背景。可打开详情或筛选「仅明显预期差」。桌面网格和手机单列使用同一入口，详情沿用响应式抽屉。

黄金事件标签关联 XAUUSD / XAUUSD=X / GC=F / GLD / IAU，仅用于事件相关性，不合并报价或行情。国家仍用于收窄。

## 当前能力和边界

- 展示区间内背景事件、数据发布数、可评分数与明显偏差数。统计只代表当前查询结果，不代表完整宏观日历覆盖。
- 重要性沿用既有 EventImportance，不因为市场反应或预期差改写重要性。
- 有结构化证据时展示首发实际值、一致预期、原始差值与来源。没有证据时明确未录入；不从正文或价格变化推测数值。
- 标准化为 actual−consensus 除以之前最多60次同口径发布误差的样本标准差，最少12次；排除当前/未来时间及重复时间。零尺度不评分。
- 阈值是试行参数：|S|<0.5接近预期，|S|≥1.5明显偏差；不是经过历史验证的交易规则。暂未引入逐指标舍入容忍量、调查离散度或稳健尺度。
- 明显偏差用琥珀色事件卡片与图表标记强调。同日多个 macro.release 保留独立身份，同根K线聚合时优先展示绝对预期差最大的事件。
- 精确时间事件在1h/4h上对齐实际K线，日线按日期；原始时间保留。只有日期的旧事件放在该日首根可用K线上，不能据此推断小时级归因。休市内事件映射到下一可用K线。
- 不新增表、抓取器、API或生产数据。本轮不修改人工趋势线，不自动判断反转，不输出未来概率。

生产审计时事件库没有结构化数据发布。部署代码本身不会产生一致预期，因此初次使用主要提供历史背景对照和缺失提示。数据来源接入、历史首发核对、稳定发布实例及快照账本仍是后续任务。

## 复用与证据契约

复用 MarketEvent、现有 for-chart / chart-markers API、事件过滤、详情抽屉及 ingest 校验/写入。新增纯函数为演示阶段的消费端计算，不是新的 canonical 宏观存储。

可选的 `payload.macroRelease` 是事件所引用发布证据的展示投影，actual 应来自已有 MacroObservationVintage 或可核对的官方首发，不能作为独立宏观事实源。后续正式接入必须通过既有 writer，使用版本引用及独立的一致预期快照事实；不通过此字段另建实际值抓取链。历史误差必须来自同一指标、同一单位、同一变换及同一预期来源的可审计首发样本。

字段：

| 字段 | 要求 |
|---|---|
| actual / consensus | 有限数值；同参考期、口径、单位；缺失不能写0 |
| unit / referencePeriod | 非空单位与参考期 |
| releaseAt / consensusAsOf | 带时区的完整时间；预期快照严格早于发布 |
| consensusSource | 调查来源名；不能用本站模型预测冒充 |
| consensusSourceUrl / actualSourceUrl | 可核查的 HTTP(S) 来源链接 |
| isInitialRelease | 必须 true，来源已确认首发 |
| historicalErrors（可选） | `{releaseAt, actual, consensus}` 数组，发布前的同口径历史误差样本 |

现有 CLI ingest 在此字段存在时校验证据结构和时间一致性；旧事件可继续不提供它。形式校验不能证明来源真实或许可有效，导入前仍须核实。示例仅存在于测试夹具，不导入真实库。

## 后续优先级

1. 确定并核实市场调查一致预期来源、授权和历史发布前时间证据，扩充实际发布覆盖。
2. 接入发布实例/预期快照与已有版本事实，完善筛选分页和覆盖统计。
3. 用人工趋势线与确认案例实现突破过程量化，再验证事件背景与反转的关系。

## 本轮验证

- 16项相关测试通过：预期时刻与首发证据、未来样本排除、重复样本、零尺度、黄金关联与国家过滤、1h/4h/日线标记定位。
- 相关文件 ESLint、TypeScript 检查以及最终 `npm run build` 通过。
- 浏览器使用实际研究组件和本地测试夹具，检查桌面网格、390px手机单列、明显偏差筛选、详情来源及关闭操作。测试夹具仅用于界面验证，未写数据库；未进行真实一致预期数据的端到端验证。
- 尚未提交、部署或修改香港数据。
