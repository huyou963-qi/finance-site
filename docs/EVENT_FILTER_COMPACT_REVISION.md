# 第一轮补充：以 K 线可用高度为优先

依据用户对第一轮截图的反馈，撤销顶部来源分页与多行工具区，采用紧凑布局。本记录取代第一轮记录中的高度与分页布局建议；筛选语义、来源偏好隔离和手机暂存行为沿用。

## 当前实现

- 系统事件 / 用户事件恢复左侧纵向分页，两端均可见，支持上下方向键切换。
- 面板默认高度 180px，可拖至最小 150px。此前版本桌面默认 360px、手机最小 420px；当前默认分别减少 180px 与 240px。该数字指事件面板本身，不包含行情页已有的折叠把手。
- 搜索、类型、重要度、高级筛选、来源管理、上图开关、显示设置和视图放在同一条工具栏。窄屏横向滚动工具栏，保留手机筛选面板，避免通过换行增加高度。
- 已选条件保留一条紧凑横向摘要，条件多时横向滚动，不不断叠加行数。
- 类型、高级筛选使用浏览器原生浮层；来源管理、关联范围、恢复默认和颜色设置放入模态浮层，打开不会改变事件面板或 K 线的布局高度。
- 事件卡片改为三行：日期与来源、单行标题、类型与详情/定位操作。移除重复的标记名称和标题，以及卡片内宏观证据摘要；完整内容仍通过原有详情查看。时间线卡片约 78px 高、240px 宽，长标题截断并提供悬停全文。
- 紧凑版使用新的高度偏好键，避免上轮保存的高面板覆盖本轮默认值；旧存储保留。用户此后拖动的高度仍会保存。

## 验证

`node scripts/test/event-filter-browser.cjs` 在 1280px、390px、320px 下检查：

- 默认面板实际高度为 180px，样例卡片不超过 80px。
- 打开类型、高级筛选与用户包管理后，面板仍为 180px。
- 来源隔离、清除内容、关闭上图仍保留列表、手机取消/应用及焦点恢复继续通过。
- Skill 下载与导入范围可操作，无页面横向溢出，无浏览器运行错误。
