# 美国国际收支分析

本文档与宏观页内置模板、`usBalanceOfPaymentsAnalysisLayout.ts`、`us-balance-of-payments-analysis-framework.md` 保持一致。

## 分析目标

美国国际收支模板不重复“美国对外部门与美元”已有的经常账户总差额、贸易差额和净国际投资头寸，而是回答四个结构问题：

1. 服务、初次收入和二次收入如何缓冲或扩大经常账户失衡；
2. 美国居民对外取得资产与境外投资者增持美国负债，哪一端主导季度资金流；
3. 美国对外融资依赖直接投资、证券投资还是其他投资；
4. 融资最终沉淀为怎样的外部负债存量。

## 分析顺序

### 1. 经常账户的非货物缓冲

- 服务差额为正并扩大：服务出口在缓冲货物贸易逆差。
- 初次收入差额改善：美国对外资产收益相对外国持有美国资产的收益仍有优势。
- 初次收入由顺差转逆差：净负债积累和较高的对外收益支付开始侵蚀收益优势。
- 二次收入通常为负，代表经常转移的结构性流出。

图 1 不是完整经常账户，必须联读既有 `IEABC` 和 `BOPGSTB`。

### 2. 资产、负债和金融账户净借贷

BEA 的符号约定必须保持：

- `IEAA` 正值：美国取得更多对外金融资产，即金融流出；
- `IEAI` 正值：美国发生更多对外金融负债，即金融流入；
- `IEANLF` 正值：金融账户净贷出；负值：金融账户净借入。

`IEANLF` 是 BEA 官方总量，包含金融衍生品净交易。不得用 `IEAI - IEAA` 替代并冒充完整金融账户差额。

### 3. 外部融资质量

- 直接投资：通常期限更长、黏性更高；
- 证券投资：更受利率、资产回报和全球风险偏好影响；
- 其他投资：主要含存贷款、贷款与贸易信贷，对银行体系和美元流动性更敏感。

负值表示撤资或负债净偿还，图表不可截断负值。

### 4. 外部负债存量

证券投资负债占比高，既体现美国资本市场吸收全球储蓄的能力，也使负债市值对利率和资产价格重估更敏感。其他投资负债上升，则提高银行融资与短期流动性冲击的传导速度。

期末头寸变化不仅来自交易，还包括价格、汇率和其他数量调整；不得用图 3 的季度流量直接解释图 4 的全部变化。

## 典型组合

| 观察 | 典型结论 |
|------|----------|
| 服务顺差扩大、初次收入改善 | 非货物项目缓冲贸易逆差，外部失衡质量改善 |
| 初次收入转负、净 IIP 同时恶化 | 美国长期收益优势减弱，外部失衡更趋结构化 |
| 金融账户净借入扩大、直接投资流入主导 | 外部融资增加但黏性相对较高 |
| 金融账户净借入扩大、证券投资流入主导 | 对全球风险偏好、美国利率和资产回报更敏感 |
| 其他投资流量和存量同步跳升 | 银行、存贷款或美元流动性渠道主导，应联读金融条件模板 |
| 证券投资负债存量上涨而当期流入不强 | 可能主要由价格或汇率重估推动 |

## 数据、更新与口径

- 来源：BEA，经 FRED API 获取；数据库只保存原始水平值。
- 国际交易账户完整标准口径共108条：季度、季调、百万美元；其中本域 seed 107 条，复用“美国对外部门与美元”已持有的 `IEABC` 1 条。本次在原四图指标之外补充98条，供指标目录和后续模板复用。
- 108条的筛选边界是 FRED *U.S. International Transactions* 发布包内仍列示的季度季调百万美元序列；不重复保存年度、季度未季调、十亿美元缩放副本和已标记 discontinued 的历史副本。
- 国际投资头寸3条序列：季度期末、未季调，自2006Q1起。
- 更新分组：`us.bea.international_transactions`、`us.bea.iip`。
- 自动更新：国际交易账户108条绑定同一个 `economic_calendar` 发布包，由 `data:sync-calendar` 对齐 Current Account 发布事件，再由 `data:worker` 增量拉取；IIP发布包没有稳定的经济日历标题，仍按 `probe_interval=168h` 检查。
- 人工立即更新：管理端“立即同步发布包”，或逐条执行 `npm run data:sync-one -- sched_fred_<ID>`。
- 建议计划任务：每小时运行 `data:sync-calendar`，每5分钟运行 `data:worker`。
- 数据质量例外：`IEASAD`（季节调整差额）仍列在官方发布包中，但最新非空值停在2019Q4。系统保留其完整历史并继续随发布包探测，以便官方恢复报数；不把缺失季度补零，也不伪造更新状态。
