# 行情画图工作台

## 设计依据与范围

参考 TradingView 的 [工具分组](https://www.tradingview.com/support/solutions/43000703396-drawing-tools-available-on-tradingview/)、[同标的图形同步](https://www.tradingview.com/support/solutions/43000629998-my-drawings-do-not-get-synchronized-across-charts-or-layouts/) 与对象管理思路，在既有 Lightweight Charts 上自建 SVG 工作台，不引入第三方图表账户或 SDK。

- 线与趋势：趋势线、射线、延长线、水平线、垂直线、三点平行通道。
- 形状与标注：矩形、椭圆、箭头、文字。
- 分析与交易计划：有方向的斐波那契回撤及延伸、价差／百分比／自然日测量、三点多头／空头仓位（入场、目标、止损及盈亏比）。仓位图形仅作分析标注。
- 对象管理：名称、选择、显示／隐藏、锁定／解锁、复制、删除、清空确认；锁定图形不能拖动、修改或删除。
- 图形设置：颜色、1–4px 线宽、实线／虚线／点线、UTC 时间和价格坐标。选中图形可拖动锚点，拖动完成记为一次撤销操作。
- 磁吸到当前 K 线的开高低收；支持撤销／重做（最多 50 步）、Ctrl/⌘ Z、Ctrl/⌘ Shift Z 或 Ctrl Y、Esc 取消草稿、Delete 删除未锁定的选中对象。

桌面使用工具栏下拉工作台；手机使用底部可滚动面板，提供同样的工具、对象管理和设置入口。定点完成自动回到选择模式；图形的绘制与命中测试共用几何，避免看到图形却无法选中。

## 数据归属与保存

服务端范围为 `source:symbol:adjust`，与用户 ID 构成联合主键。图形使用真实时间／价格坐标，同标的不同周期共享图形；日线锚点在周线或盘中图上按实际交易柱时间插值。不同复权方式分开保存，避免同一价格坐标在复权变更后产生误导。

| 状态 | 保存方式 |
| --- | --- |
| 已登录且在该用户自选股中 | 服务端自动保存，并在本地保留缓存及未提交草稿 |
| 已登录且非自选股 | 按用户 ID 隔离的本地存储 |
| 游客 | 游客本地存储；提示登录后自选股可同步 |

加入自选股时迁移本地图形；与已有云端内容合并，碰到同 ID 的不同版本时保留两个对象。移出自选股时转为本地保存，已有云端历史保留。重新加入时恢复／合并。游客的旧 `kline-drawings-v1` 图形只向游客空间迁移，不自动归给共享浏览器上之后登录的人。

`GET/PUT /api/tools/market-drawings`：所有数据所属用户取自服务端会话；PUT 再检查该用户自选股成员资格。客户端用户 ID 仅检测过期账号。输入限制 300 个对象、500 字标注、300KB 请求文本；只保存允许的字段，拒绝异常坐标、样式和重复 ID。

图形变更立即写本地草稿，云端写入延迟 500ms 并串行处理；切周期卸载、页面隐藏和退出时尝试提交。跨实例同范围先等上一写入结束。回到页面／点击同步时读取云端最新内容；不承诺推送式实时协作。

服务端 revision 乐观并发校验与事务阻止覆盖其他设备的新版本。遇到冲突保留本地草稿，用户可以「合并并保留双方图形」或「采用云端版本」。合并保留双方对象，因而不会自动解释一台设备的删除意图；需要在对象管理中再整理。联网失败时明确提示，重试同步会重新验证归属和版本。

## 部署与验证

新增 `UserMarketDrawing` 和迁移 `20261011120000_user_market_drawings`，部署需 `npm run db:migrate`，账户删除时级联清理其图形。

- `src/lib/chart/marketDrawings.test.ts`：模型输入、账号隔离、锚点修改、绘制几何、方向和跨周期插值。
- `npx dotenv -e .env.local -- tsx scripts/test/market-drawings.integration.ts`：只允许本地数据库，创建并清理临时账户，验证会话、跨用户隔离、自选股写入约束、并发冲突和移出后的历史保留。
- `npm run verify:commit`：完整测试、Prisma、lint 和生产构建。
