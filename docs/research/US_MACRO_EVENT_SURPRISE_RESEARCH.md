# 美国宏观事件预期差与跨资产拐点研究：现状及建议

研究日期：2026-10-12（Asia/Shanghai）。本轮仅研究、只读审计生产库；未改业务代码、调度或生产数据。工作区已有较多未提交改动，本文描述本地当前代码与当日生产库快照，二者不假设完全相同。

## 1. 结论

现有事件系统可以复用，但还缺少“逐次宏观发布 + 发布前预期快照 + 首发版本 + 预期差计算 + 市场反应验证”这一层。继续批补叙事事件，无法单独满足预期差研究。

建议先实现历史区间研究，再验证预测能力：选择黄金图上一段区间，加载全部重要美国宏观发布，显示首发与当时预期，突出异常预期差，并对照黄金、美元、美债和股指的反应。验证后再增加发布前风险监测。

### 已发现的日历问题

us.fed.fomc 的 calendarMatch 为 2026-10-12T12:30:00Z，标记 FOMC Press Release。官方例会日历下一次会议为 10 月 27–28 日。本地 fredReleaseCalendar/catalog.ts 把该包同时映射至 release 18（H.15）和 101，故当前包调度语义不能直接充当 FOMC 决议时间。需核对映射、官方时刻、声明与纪要的区别；不得把 nextRunAt 当事件发生时刻。

官方对照：[美联储会议日历](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)。

## 3. 可以复用的系统及具体缺口

- `.cursor/skills/market-event-ingest/SKILL.md`：叙事检索、权威来源交叉验证、externalId、语义去重及标签合并。继续用于政策、讲话、地缘背景，不让 AI 凭新闻语气补造数值预期。
- `marketEvents.ts` / `marketEventsIngest.ts` / `eventTaxonomy.ts`：事件事实、共享词表及导入链。macro.release 已有类型，无须第二套事件词表。
- `assetEventResolver.ts` / `chartSymbolProfile.ts`：当前主要是资产精确匹配、行业前缀匹配和国家收窄；不是经济传导模型。normalizeAssetTag 只 trim + uppercase，不能关联现货黄金、期货和 ETF。
- `chartEventMarkers.ts`：已有列表与标记入口，但标记统一压到 UTC 日期零点，缺乏发布时间定位；同日同类型去重会吞掉同日多个 macro.release，且先取有限列表再过滤，扩容后有漏事件风险。
- `ReleasePackage` / scheduler：复用来源与官方日历，但增加“每次发布实例”，保留改期历史；probe、nextRunAt 和真实发布时间须区别。
- `MacroObservation` / `MacroObservationVintage`：复用实际值与版本 writer；不用最新修订值倒填过去首发。
- CPI / NFP nowcast、既有 Regime 和行情服务：复用计算底座。自身模型预测与市场一致预期必须分开命名；现有模型输出会更新，若用于前瞻评估须额外冻结版本。

## 4. 必须补齐的能力

### A. 逐次发布与预期快照（优先）

每次发布具备稳定 ID、发布包、指标、参考月份/季度、口径、单位、计划时刻、实际公开时刻、系统首次捕获时刻、源与证据。

发布前预期记录必须只追加：provider、统计口径（中位数/均值）、snapshotAt、sourcePublishedAt、值、调查人数及离散度（源有才保存）、授权和来源凭据。发布后抓到的历史预期，只有源能证明其发布前版本才可用于严格回测。

一次 CPI 发布同时包含 headline/core、MoM/YoY；就业报告包含新增非农、失业率、时薪和前期修订。按发布实例组织分项，不能把四个分项误当四次独立宏观冲击。

建议新事实语义为“发布实例”“预期快照”；与 MarketEvent 和现有版本账本关联。实际数值以现有 canonical store 为准，发布记录引用具体版本。新表须说明血缘、幂等键、历史补建证据与重建边界，避免复制宏观事实。

### B. 一致预期来源

这是第一优先的数据依赖。现有官方/FRED 底座不自动提供市场调查一致预期。

可评估授权经济日历 API，或带授权和时间证据的文件导入。Trading Economics 官方 API 文档包含 Actual、Previous、Forecast、TEForecast、Revised、LastUpdate 等字段；技术上符合候选方向，但历史发布前版本、商用展示/存储权、覆盖范围、预算均须实际核实，不能由接口字段推出授权。

[TE 日历 API 字段](https://docs.tradingeconomics.com/economic_calendar/ticker/)。Forecast 与 TEForecast 必须按供应商定义区分，不能混为市场一致预期。

没有一致预期时标为“预期缺失”；可单独显示“相对本站模型的偏差”，不能显示“市场符合预期”。项目已有 US_NFP_NOWCAST.md 记录若干来源的条款限制，接入前复用已有调研。

### C. 预期差引擎

原始偏差：D = 首发实际值 − 发布前冻结的一致预期。

跨指标标准化：S = D / 发布前历史同口径预测误差的滚动标准差。尺度只使用过去数据，可先试 36–60 次发布；稀疏样本、零尺度、口径变化、极端时期须有处理及提示。必要时用稳健尺度/历史分位数做对照。

暂定研究阈值：|S| < 0.5 为接近预期，0.5–1.5 中等，≥1.5 明显，≥2 强烈。阈值为待校准参数，不是已验证规律；辅以原始差值、公布舍入精度与同类历史分位数。

数值高于/低于预期、增长/通胀方向、对具体资产的传导方向分别显示。非农强于预期可能同时改善增长预期与提高利率预期，不能简单标成对所有资产“利好”。前期修订单列；不要未经验证对相关分项求和。

FOMC 分开看当次利率、未来路径/点阵图、声明及记者会；地缘事件和非计划政策只能做带证据的定性变化，不能强套数值 S。

### D. 资产关联与市场反应

增加稳定资产族，例如 GOLD 关联 XAUUSD、GC=F、GLD，但三者行情、交易时段、期货换月、ETF 跟踪误差仍分别处理，不能合并成同一价格序列。

事件关系描述渠道：实际利率、美元、增长、通胀、避险、流动性；包含关联强度、条件、证据和版本。先做透明人工映射，再用数据校准。复用既有 Regime，不新建同义状态算法。

首批资产：现货黄金、美元指数、2Y/10Y 收益率、SPY/QQQ、原油。收益率用 bp 变化，与债券 ETF 收益分开。

计算发布前与发布后窗口：日线先做 T−5/T−1、T+1/T+3/T+5/T+20；有合规历史盘中行情时再做 5/30/60 分钟。日收盘无法隔离单一公告冲击，多公告重叠、跨休市、非同步行情和源延迟必须显示。价格标准化反应使用发布前波动尺度。

### E. 图表与区间研究

区间选择后并列展示：全部重要发布、数值预期差、政策/地缘背景、前后趋势及跨资产反应。支持只看大预期差，但默认研究列表保留接近预期和缺失预期，避免只找能解释拐点的事件。

标记大小/亮度表达偏差绝对值；颜色表达数值方向，资产解释另列。点击展开实际/预期/差值/历史分位数/首发修订/发布时间/证据/跨资产反应。未来事件用空心标记，仅显示日程、已有预期和风险区间。

将同日同类型去重改为发布实例身份去重；分项聚合为一个卡片；所有筛选在分页/截断之前应用。分钟图保留原始发布时刻，休市映射仍保留真实时间。

桌面沿用图表侧栏；手机提供相同的日期区间输入、事件筛选、底部详情与跨资产切换入口，不要求精确拖选才能使用。

## 5. 如何验证用户假设

将假设改写为可证伪问题：“在给定基本面状态和既有趋势下，重要且大幅偏离预期的发布，是否提高随后趋势反转概率？发布前跨资产变化是否有额外预测力？”

先冻结趋势定义（例如过去20/60交易日斜率与波动尺度）、反转定义及5/20交易日观察窗口，避免用事后确认的峰谷或未来数据做信号。

比较完整样本的三组：接近预期发布、大预期差发布、匹配的无发布交易日。衡量反转率、延续率、反应大小、效果区间，并控制 Regime、波动、原趋势、同时发布、连续冲击。按日期滚动训练/验证；阈值、分项权重不能根据红圈或测试集调优。

发布前背离只能叫“价格提前调整/异常”，其原因可能包括公开领先数据、仓位、流动性或其他新闻；价格本身不能证明信息泄露。不得从同一窗口的价格反应反推 surprise 后，又用 surprise 解释该价格。

宏观冲击的市场影响会随环境改变；FOMC 当次利率和未来路径具有不同影响，已有研究支持分别建模。参见 [宏观新闻与注意力研究](https://www.federalreserve.gov/econres/feds/files/2025022pap.pdf)、[FOMC 跨资产目标与路径冲击](https://www.federalreserve.gov/pubs/ifdp/2006/886/ifdp886.htm)。这些研究不证明“只有重大预期差才反转”。

## 6. 推荐推进顺序

1. 修正研究数据的时间语义，确定一致预期来源、历史可见性与授权；补黄金资产族。核实截图红圈对应的精确日期，不能凭像素认定事件归因。
2. 第一版历史研究：CPI（含核心）、就业报告、核心 PCE、ISM；有合格预期的样本计算 S，缺失清楚标记；黄金、美元、美债、股指联动。FOMC 可先作为定性上下文，数值政策预期差随后补齐。
3. 完成事件反应和完整样本检验，确认“预期差—趋势反转”的增量效果。
4. 再开发未来1–2周监测：事件日程、冻结预期、本站 nowcast 与一致预期之差、历史影响、当前跨资产背离。输出条件情景和经样本外校准的风险概率；没有验证能力时只显示观察项。

第一版验收闭环：选中历史区间 → 不漏重要发布 → 查到当时预期与首发 → 算出可复核差值 → 图上高亮 → 查看同步资产反应。随后再决定是否值得建设拐点预测。
