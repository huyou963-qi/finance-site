# 美国 CPI 分项 Nowcast

页面：顶栏「指标预测」→ `/forecast/us-cpi`（功能页 `forecast-us-cpi`）。接口：`GET /api/forecast/us-cpi`。
代码：`src/lib/forecast/usCpi/`（`model.ts` 纯函数模型、`backtest.ts` 回测与精度、`inputs.ts` 读库、`service.ts` 组装与 30 分钟缓存、`relativeImportance.ts` BLS 权重表）。

## 模型

CPI 拆为 18 个叶子分项，各用最直接的高频代理做滚动 OLS（窗口 120 个月），按 BLS 相对权重（前一年 12 月值 × 此后相对价格漂移）加总到食品 / 能源 / 核心商品 / 核心服务 / 核心 / 总体。

| 分项 | 代理 |
| --- | --- |
| 汽油 | EIA 周度零售汽油价 `GASREGW` 月内 1–22 日均值 → 未季调汽油 CPI，再加过去 3 年同月「季调 − 未季调」差 |
| 燃油 / 机票 | 纽约港取暖油 `DHOILNYH` / 墨西哥湾航油 `DJFUELUSGULF` |
| 电力 / 管道燃气 | 亨利港天然气 `DHHNGSP`（滞后 0–2 月） |
| 家庭食品 | PPI 最终需求食品 `PPIDFS`（滞后 1 月） |
| 二手车 | Manheim 批发价指数 `mds:cox_us_manheim_used_vehicle_value_index_sa`（滞后 1–3 月，月频） |
| 房租 / 业主等价租金 | CPI 自身历史 + ZORI 长期传导；满足发布可用性与此前滚动验证门槛时，加入滞后1月的近期3月平均环比 |
| 其余（新车、服装、医疗、酒店、残差三项） | 自回归 + 12 个月均值 + 残余季节性 |

残差分项（其他核心商品、其他交通服务、其他核心服务）= 上级指数 − 已建模分项，保证加总口径与官方一致。某分项回归无法估计时退回 12 个月均值并在页面提示。

**信息集**：CPI、PPI、Manheim、ZORI 截至上月；日/周频价格只取当月「已观测」天数——目标月未结束时取零售汽油价在当月的最新日期，目标月已结束（CPI 公布前）取全月；当月尚无油价时沿用上月末价格。**回测、80% 区间和克利夫兰联储对照都按同一截止日重算**，所以月初区间如实更宽、月末更窄，无前视。

按截止日的回测精度（2018 年以来剔除疫情月，研究阶段测算）：

| 高频数据截至 | 总体 MAE | 核心 MAE |
| --- | --- | --- |
| 1–7 日 | 0.123 | 0.078 |
| 1–14 日 | 0.105 | 0.077 |
| 1–22 日 | 0.089 | 0.077 |
| 全月 | 0.079 | 0.077 |

## 验证（2026-09，研究阶段 Python 与 TS 移植逐项一致）

2018-01 至 2026-08 滚动样本外，剔除 2020-03~06（N=98）：

| 环比 MAE（百分点） | 本模型 | 克利夫兰联储 nowcast（每月 22 日） | 过去 12 个月均值 |
| --- | --- | --- | --- |
| 总体 | **0.089** | 0.124 | 0.190 |
| 核心 | **0.077** | 0.099 | 0.099 |

- 在验证期（2012–2017）按分项挑选「回归 / 均值 / 平均」反而使测试期变差（房租 2017 年前无 ZORI），故保留预设方案；「残余季节性」特征先在验证期确认有效才采用。
- 局限：回测用当前版本季调数据（BLS 每年 2 月修订 5 年季节因子），误差略被低估；2025-10 停摆月及其后一月不参与估计和评估；公布值取整到 0.1，取整命中率仅三到五成，应以 80% 区间解读。
- 克利夫兰联储 nowcast 为第三方模型输出，**不入库**：`clevelandFed.ts` 在服务端读取官网图表 JSON（`nowcast_month.json`，约 7.6MB，香港机房可直连），进程内缓存 6 小时、失败 10 分钟后重试；页面把它画成回测图的对照虚线、精度表的基准行，并给出它对当前目标月的最新值。取数口径与本模型一致（目标月同一截止日含之前最后一次）。源站不可达时页面自动省略该对照。

## 租金与 OER 更新机制（2026-10-15）

三层必须分开，不能拿市场租金覆盖 CPI 实际值：

| 层 | 来源与更新 | 口径 |
| --- | --- | --- |
| 已公布实际值 RENT | BLS 经 FRED `CUSR0000SEHA`，`us.bls.cpi` 发布包 | 季调指数，1982–1984=100 |
| 已公布实际值 OER | BLS 经 FRED `CUSR0000SEHC`，同一发布包 | 季调指数，1982年12月=100 |
| 市场租金代理 | Zillow 官方 `Metro_zori_uc_sfrcondomfr_sm_sa_month.csv`，`zillow_us_zori_sa`，12小时探测 | 全美、平滑季调、美元/月；每次整表读回历史修订 |
| 预测 | 数据入库后，页面/API首次缓存过期请求触发重算，服务端缓存30分钟、浏览器私有缓存5分钟 | 模型输出不入库，不是另一条真实租金/OER订阅 |

官方依据：[BLS 租金/OER方法](https://www.bls.gov/cpi/factsheets/owners-equivalent-rent-and-rent.htm)、[Zillow 发布日历](https://www.zillow.com/research/calendar/)。
Zillow 月初市场报告与16日完整月表是不同发布批次；报告数值的季调、历史修订未确认前，不拼接进 `_sa` 序列。
12小时探测只是限制本站额外等待，不能令上游提前发布。seed 同样使用12小时常量，重复部署保留更早/已到期的抓取时间，避免每次部署重新后推。

### 模型：不是取消经济传导，而是取消“只有固定7月滞后”

- 原候选：CPI 自身滞后 + ZORI 对数环比12月均值、最新使用 t−7 月。
- 增量候选：在原候选上追加 ZORI 对数环比3月均值、最新使用 t−1 月。
- RENT、OER 各自比较目标月之前24个月的逐月滚动预测，只使用同时可比且未排除的月份；各次拟合严格早于各次验证月。
- 至少18个可比月份，增量候选的 MAE 至少改善5%，且本次输入完整、回归可估计，才启用。否则保留原模型；ZORI 全部不可用时退回自身历史，并披露状态。
- 按当前截止日一致地回测：截止日17日之前保守关闭近期候选，17日起允许 t−1。17日是站内留出的发布缓冲，不是 Zillow 承诺的精确发布时间；即使过了17日，未取到的值仍为缺失，不能填造。目标月已结束用全月截止日，仍然只取 t−1 或更早的 ZORI，不用目标月市场报告。
- API `components[].shelterDecision` 披露模式、两候选验证MAE、样本数、输入截止月份和回退原因；现有桌面/手机共同使用的方法列显示实际选择。
- 回测/精度曲线缓存改用全部模型输入的内容指纹，ZORI 同月历史修订也会使其失效。

2026-10-15香港只读快照，2019-01至2026-08，剔除疫情/停发影响后86个可比月，开启近期候选的月中以后窗口：

| 季调环比 MAE（百分点） | 原固定滞后 | 受控近期候选 |
| --- | --- | --- |
| RENT | 0.069832 | 0.066480 |
| OER | 0.064648 | 0.063674 |
| RENT，2023年以来42月 | 0.069387 | 0.065415 |
| OER，2023年以来42月 | 0.069842 | 0.067440 |

月中之前保持原模型，不能将以上改进声称为全天候改进。两种模型用相同真实租金/OER与ZORI历史，其他分项不参与此分项对比。
此验证使用当前修订版本，不是ALFRED首发版本或历史ZORI发布日期重建；固定发布可用性门槛也只是保守近似。选择门槛属模型设计，结果不是未来改善保证，也不是新的严格PIT回测；原文2026-09精度表不代表本次新模型。

### 已确认的生产漏更与修复边界

2026-10-14 12:36/12:41 UTC抓取时FRED尚未发布9月两分项，记SKIPPED；日历却推进至11月。此前“跑过”或“库内等于当时上游”不足以证明本期消费完成。
新增仅针对 `us.bls.cpi` 的观测期门槛：所有可调度成员的最旧 `lastObsDate` 必须达到发布月上一个月；否则保留已有探测点或恢复2小时有界探测，不允许直接跳过本期。
10月15日在worker和日历双锁下通过现有连接器补抓两条：9月 RENT=450.429、OER=445.265，均各新增1点，成员及发布包排期保持不变。随后检查发现同根因影响全包其余27条，亦在双锁下有界重跑，各新增1点，逐项确认排期未变；最终29/29条均达到2026-09。模型依赖的 `CPIAUCNS` 单独订阅也已为9月。
服务端不会定时主动重算预测，缓存过期后的访问才计算；再考虑浏览器5分钟缓存，展示通常在入库后约35分钟缓存窗口加下一次请求更新。预测目标只在全部CPI输入到齐后推进，不能只看RENT/OER已到齐。
