# 美国 CPI 分项 Nowcast

页面：顶栏「指标预测」→ `/forecast/us-cpi`（功能页 `forecast-us-cpi`）。接口：`GET /api/forecast/us-cpi`。
代码：`src/lib/forecast/usCpi/`（`model.ts` 纯函数模型、`backtest.ts` 回测与精度、`inputs.ts` 读库、`service.ts` 组装与 30 分钟缓存、`relativeImportance.ts` BLS 权重表）。

## 模型

CPI 拆为 18 个叶子分项，各用最直接的高频代理做滚动 OLS（窗口 120 个月），按 BLS 相对权重（前一年 12 月值 × 此后相对价格漂移）加总到食品 / 能源 / 核心商品 / 核心服务 / 核心 / 总体。

| 分项 | 代理 |
| --- | --- |
| 汽油 | EIA 周度零售汽油价 `GASREGW` 月内 1–22 日均值 → 未季调汽油 CPI，再加过去 3 年同月「季调 − 未季调」差 |
| 燃油 / 机票 | 纽约港取暖油 `DHOILNYH` / 墨西哥湾航油 `DJFUELUSGULF` |
| 电力 / 管道燃气 | 亨利港天然气 `DHHNGSP`（滞后 0–2 月） |
| 家庭食品 | PPI 最终需求食品 `PPIDFS`（滞后 1 月） |
| 二手车 | Manheim 批发价指数 `mds:cox_us_manheim_used_vehicle_value_index_sa`（滞后 1–3 月，月频） |
| 房租 / 业主等价租金 | Zillow 观测租金 `mds:zillow_us_zori_sa`（12 个月均值滞后 7 月）+ 自身滞后 |
| 其余（新车、服装、医疗、酒店、残差三项） | 自回归 + 12 个月均值 + 残余季节性 |

残差分项（其他核心商品、其他交通服务、其他核心服务）= 上级指数 − 已建模分项，保证加总口径与官方一致。某分项回归无法估计时退回 12 个月均值并在页面提示。

**信息集**：CPI、PPI、Manheim、ZORI 截至上月；日/周频价格只取当月 1–22 日。回测与实时同一口径，无前视。

## 验证（2026-09，研究阶段 Python 与 TS 移植逐项一致）

2018-01 至 2026-08 滚动样本外，剔除 2020-03~06（N=98）：

| 环比 MAE（百分点） | 本模型 | 克利夫兰联储 nowcast（每月 22 日） | 过去 12 个月均值 |
| --- | --- | --- | --- |
| 总体 | **0.089** | 0.124 | 0.190 |
| 核心 | **0.077** | 0.099 | 0.099 |

- 在验证期（2012–2017）按分项挑选「回归 / 均值 / 平均」反而使测试期变差（房租 2017 年前无 ZORI），故保留预设方案；「残余季节性」特征先在验证期确认有效才采用。
- 局限：回测用当前版本季调数据（BLS 每年 2 月修订 5 年季节因子），误差略被低估；2025-10 停摆月及其后一月不参与估计和评估；公布值取整到 0.1，取整命中率仅三到五成，应以 80% 区间解读。
- 克利夫兰联储 nowcast 为第三方模型输出，不入库，页面只引用研究阶段的对照结论。

## 维护

- **每年 1 月**：BLS 发布上年 12 月相对权重后，在 `relativeImportance.ts` 追加一年（未追加时沿用最近一年）。
