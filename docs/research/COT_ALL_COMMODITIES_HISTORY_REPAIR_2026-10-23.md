# 香港生产 COT 全品种历史核查与修复

验收日期：2026-10-23（北京时间）。本次承接黄金单品种修复，对站内全部 23 个商品的 46 条管理基金多空序列检查并补齐。

## 结论

黄金上一轮补数已在香港生产库生效。其余 22 个品种均存在首次只导入最近 60 周的问题，修复前各有 76 周，从 2025-05-06 起。生产 47 条 COT 订阅（含独立黄金净持仓）全部启用、无错误，增量更新正常。

本次香港生产新增 43,040 条历史观测，修订 38 条错值。46 条多空序列修复后共 48,508 条，逐值对照官方源：缺失 0、差异 0、额外日期 0。黄金净持仓原有 894 周保留，全部与多空相减一致。

## 额外发现及修复

- KCBT 旧订阅 metadata 使用 `WHEAT-HRW` 或 `CHICAGO BOARD OF TRADE` 的宽泛匹配，可能取到持仓量更大的 CBOT 小麦。实际查到 19 周多头、空头误配，共 38 点，已按官方值修正；修改前数据与订阅完整备份。
- 小麦 2013 年更名：CBOT 始终使用 `001602`，KCBT 始终使用 `001612`。用稳定合约代码跨旧市场名称匹配，补齐更名前历史，并保证两个市场不混取。
- 可可从纽约交易所更名为 ICE，稳定代码 `073732`；天然气四个指定合约也存在历史更名。代码匹配避免丢失旧名时期。
- API 和官方 ZIP 文本解析均保留合约代码及其前导零。已知品种在读取订阅时使用代码目录的当前规则，避免数据库陈旧 metadata 继续误配；seed 也同步 `metadata.cot` 并保留其他 metadata。
- 生产 46 条多空仪器 metadata 已对齐当前目录。
- 已审计其他单市场品种的全期实际入选合约代码，均为同一稳定主合约，未发现跨市场切换。
- 新增 `data:verify-cot -- --live`：全部商品的多空完整历史逐值对照官方，而非只检查最新值存在。

## 香港执行与验收

采集源码修复已应用到 `/opt/finance-site` 与 `/opt/finance-site-jp-data`，其中独立调度器实际路径为 `/opt/finance-site-jp-data-releases/release-4hBm1Zl3`。本次没有重启网站、改数据库 schema 或执行整站部署。

```bash
npm run data:seed-cot -- --bulk-only
npm run data:verify-cot -- --live
```

另通过正式 `runDataSubscription` 入口实跑黄金三条、小麦四条、天然气两条、可可两条，共 11 条：全部无新值且源端滞后为零，无再次改写。47 条订阅全部启用、无错误、下次排期在未来。

网站生产 `/api/data/macro?source=unified` 分批实测全部 46 条序列，返回总计 48,508 个点；逐条检查首日、末日与点数通过。

回归测试 10 项、ESLint 和生产构建通过。新增测试覆盖小麦跨更名及市场隔离、旧订阅匹配规则更新、天然气及可可历史名称、ZIP 前导零代码。
