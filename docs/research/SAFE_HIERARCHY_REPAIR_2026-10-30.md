# SAFE 365 条审阅差异的根因修复

范围：2026-10-30 独立有效性核验确认的结售汇132条、全口径外债50条、国际投资头寸183条。精确清单与原来源键保存在 `src/lib/data/scheduler/safeExternal/reviewedHierarchyDefinitions.json`；清单不包含AI推算值。

## 最终行为

- 结售汇：名称包含结汇/售汇/差额区块；远期交易读取第二列的结汇/售汇/差额定义。期末未到期额和期权Delta敞口是存量，不与签约/平仓/展期等流量混用。
- 年度结售汇流量注明“最新年度累计／历年全年”，年度存量注明“最新披露期末／历年年末”。采用“最新年度”而非系统时钟“当年”，避免跨年后源表尚未发布12月数据时把上一年度累计误称全年。原日期与金额保持不变；不删除2026年真实披露值，不推算月值，不把期末存量求和。
- 外债：名称包含部门、原始签约期限和债务工具。直接投资公司间债务保留原表关联关系，不强套长期/短期分类。
- IIP：名称包含资产/负债、投资工具、部门及期限；保留无独立行的`.0`编码层级，正确识别直接投资金融/非金融部门的a/b后缀。年度年末与季度期末仍是不同序列，美元和SDR计值分开。

代码/原始叶名称/出现次数/来源键保持稳定。365条被审阅的语义路径必须与运行时原表层级一致；父级缺失、错误远期方向、资产/负债串项或已审阅成员消失时拒绝更新该域，不静默改义或由seed删除既有成员。原有BOP和69条收付款防串项校验继续保留。

## 数据落库与部署顺序

本次无schema变更。部署新版网站及worker后，在worker/calendar双锁下执行：

```bash
npm run data:repair-safe-hierarchy-definitions
```

该操作已接入`data:seed-audited-definitions`。必须先部署新解析器再写入新的scrape.sourceRowPath，否则旧版连接器会拒绝带新父级校验的成员。标准部署已在worker/calendar锁内运行定义同步；不得绕锁在旧版仍运行时提前修复。

脚本是离线、幂等、有界的定义迁移：仅按365个代码读取现存指标，整批验证来源ID/来源键、原名称或新名称、已有父级；不存在的指标不恢复。先验证所有成员，再在一个15秒上限的Serializable事务中更新名称、简称、描述及metadata，保留其他元数据。任何来源或人工名称漂移均在写入前报错，事务失败回滚。不访问或修改观测/版本账本，不写订阅或发布包，不重置nextRunAt，不执行全域seed或历史回填。

香港修复前只读快照：365条全部存在、来源键和原名称均符合清单，关联观测17416条、版本记录1864条。该快照仅保存在本机。部署后应逐项对比ID、观测数量和最新值、订阅规则与nextRunAt，再核验365个名称及语义路径，并重复执行脚本确认changed=0。

## 验证与资源预算

三份独立下载的官方原始Excel已验证365个代码/来源键/新名称/语义路径；原数值、观测期间、单位全部一致。回归覆盖远期第二列、年度未完成期间、真实零/负值、外债部门/期限切换、IIP资产负债与a/b后缀、缺少父级/成员、来源漂移、幂等性和元数据保留。

生产预算：单连接、一次最多365行的索引读取和最多365条小元数据更新；无新索引、常驻进程、观测重写或历史聚合，事务超时15秒。元数据/审阅清单体积有界，不随观测历史增长。遵循2vCPU/3.4GiB混部服务器约束；构建在CI完成。

官方证据：[结售汇](https://www.safe.gov.cn/en/2023/0215/2048.html)2026-10-20原始工作簿，[外债](https://www.safe.gov.cn/safe/2018/0329/8810.html)与[IIP](https://www.safe.gov.cn/safe/2019/0627/13520.html)2026-09-29原始工作簿。132/50/183是本次已审阅修复范围，通用解析器同时防止后续同类名称再次丢失父级，不将未审阅指标计入审计覆盖数量。
