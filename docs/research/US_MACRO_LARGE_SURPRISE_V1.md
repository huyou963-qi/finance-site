# 美国宏观事件大预期差筛选（试行 v1）

用于历史事件研究、列表筛选和日线/1h/4h K 线叠加，不判断趋势反转或资产利好利空。不修改原始事件，不新增数据表；已有96条事件按读取时规则计算。

## 判定

逐个检查结构化关键分项的首发实际值与同来源调查一致预期。差值=实际值−一致预期，强度=绝对差值/该指标大偏差阈值。强度≥1的分项至少一项时，事件归为“大预期差”。多个分项不累加，同一指标不重复计数，事件展示最强分项及来源。未达标只表示未达到大偏差阈值，不等于基本符合预期；缺少证据或规则时为“未评估”。

| 指标 | 大偏差绝对阈值（含边界） |
|---|---|
| 非农 / BLS就业报告中的私营新增就业 | 75,000人 |
| ADP私营新增就业 | max(20,000人, 一致预期绝对值×30%) |
| 失业率 / 平均时薪环比 | 0.2个百分点 |
| 平均时薪同比 | 0.3个百分点 |
| CPI / 核心CPI / PCE / 核心PCE环比 | 0.2个百分点 |
| 上述通胀指标同比 | 0.3个百分点 |
| PPI及核心分项环比 / 同比 | 0.3 / 0.5个百分点 |
| ISM制造业 / 服务业 PMI | 2指数点 |
| 零售及剔除汽车、汽车汽油分项环比 | 0.5个百分点 |
| 实际GDP季环比折年率 | 0.5个百分点 |

阈值是人为设定的首版研究规则，尚未经过市场反应校准，**不是标准差、统计显著性或市场影响评分**。不以2026年全样本拟合阈值、不以价格反应反推预期差。调查上下界仅展示，不当成标准差或额外打分；不同调查来源不合并。FOMC和Jackson Hole等无适用数值调查证据的事件不强行评分。未来可依据仅含发布前已知资料的误差样本独立校准。

2026-10-12修正：ADP与BLS非农采用不同调查，不再共用75,000人阈值。ADP同时要求绝对偏差≥20,000人、相对一致预期绝对值偏差≥30%，预期为零时仅使用绝对下限。通过`releaseIdentity`的`adp:`发布包识别，BLS报告中同名私营就业分项保留原规则。8月5日44,000人对75,000人，差值−31,000人、相对偏差−41.3%，有效阈值22,500人，因此归入“大预期差”。绝对下限用于避免接近零的预期放大相对比例；仍是试行规则，没有以金价涨跌拟合。

历史报道中的调查值仍标为事后研究证据，不补造发布前快照；现有标准化S计算保留，其证据要求与本规则分开。来源、单位、首发标识、时间或参考期不合要求的分项不参加判定。Econoday CPI/PPI存在相同分项id，通过PPI标签区分阈值。

## 操作

行情页事件筛选器的“筛选：”右侧常驻显示筛选条件，勾选“仅大预期差”，列表和K线标记同步筛选；“图上显示”仍控制叠加开关。关闭筛选则显示全部符合其他条件的事件，大偏差事件仍用更大标记和◆前缀突出。按原有时间轴选择区间。卡片下方不再展示选中事件详情；桌面双击卡片或按Enter、手机点击卡片的“详情”按钮，均打开原有详情抽屉。面板默认高度180px，可拖动调整；窄屏自动换行并保留卡片可操作空间。

玫红◆=达到大偏差阈值的关键分项数值高于预期；橙色◆=低于；紫色◆=同一发布中达标关键分项方向相反。普通事件沿用原色。同一根K线多个事件时大偏差标记优先，按阈值倍数排序，并保留+N计数。详情显示实际、预期、差值、阈值、调查范围和来源。电脑和手机使用同一筛选控件，布局自动换行。

## 本批核对结果

2026-10-12本地已抓取的96条事件按修正后的规则：33条大预期差（16条高于、15条低于、2条分项相反）、56条未达大偏差阈值、7条未评估。举例：2月2日ISM制造业差值+4.1点；3月6日非农差值−152,000人；10月2日就业报告由平均时薪环比−0.2个百分点触发高亮。结果会随新增数据或规则调整变化。

页面使用只读样本接口验证电脑/390px手机布局、筛选及颜色标记；本地数据库没有本批96条事件，未为验证而写入数据库。正式上线需要发布代码，香港服务器既有事件会自动按本规则计算，无需重新导入。
