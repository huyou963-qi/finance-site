# 统一事件框架 v2

日期：2026-10-18。兼容旧事件与旧本地 JSON，无数据库 schema migration。

## 数据底层与职责

- 复用 `MarketEvent`、`stockEvents`、`eventTaxonomy`、既有 writer、资产画像与交易日对齐函数。
- 云端标准事件仍由既有 Skill/批次队列生成候选，校验后由管理员通过统一 writer 入库；不新增同源抓取器或宏观事实表。
- SEC 事件保持派生，不重复入 `MarketEvent`。
- 用户专题留在浏览器当前账号的事件包中，不自动发布到共享库。
- 新增的是显示元数据、客户端事件包与共享查询/筛选函数，不是另一套事实底座。

## 事件协议

沿用 externalId、occurredAt、datePrecision、eventType、scope、importance、关联标签、payload 等字段。可选新增：

```json
{
  "color": "#7C3AED",
  "sources": [{ "url": "https://example.com/announcement", "note": "原始证据" }],
  "readingLinks": [{ "url": "https://example.com/background", "title": "背景阅读" }]
}
```

`color` 是 #RRGGBB，缺省沿用系统配色。sources 用于事实核验，readingLinks 为可选扩展阅读，支持 HTTP(S)，不要求 Wikipedia。旧 Wikipedia 主链接继续保留，并在详情中归为背景阅读。

为兼容现有数据库，writer 将这些字段保存到既有 payload，DTO 同时投影为顶层字段；更新时保留其他证据。不得直接另建颜色事实表。当前数据库的 updatedAt 是本次系统更新时点，不是历史首发时间；没有历史证据时不能据此宣称 PIT。

本地解析完整保留原始字段、精确时刻、sources、readingLinks、宏观证据和研究阶段。新文件可带 schemaVersion=2 和 pack 元数据；旧文件仍可用。只知道日期时使用 DATE，精确时刻必须带时区，不生成虚假时间。

## 资产相关性与查询

- 直接关联：资产标签命中；行业关联：GICS 上下层匹配，并限于行业/国家/跨市场范围，避免把同行公司的单票事件扩散到其他公司。
- 宏观关联：资产画像对应地区，且事件为 COUNTRY/CROSS 范围的宏观、政策、官方讲话；通过规则命中，不把所有同国公司事件扩散。
- 用户可选直接资产、资产与行业、包含宏观关联；国家仍作为收窄条件。
- 相关性在数据库分页前处理，避免先截断全站结果再找当前资产。
- /markets 自动续取共享事件分页；SEC 沿用既有聚合服务的单次上限，超大历史披露范围仍应分时间区间查看。
- 详情展示命中原因；本地事件按包显示范围加载，不伪造 assets 标签。

## 一致筛选与绘制

行情页用 useChartEvents 生成一份事件集合，供卡片、详情与主图共用。类型、公司细类、来源、重要性、搜索、人物和机构统一判定。大预期差条件要求有效的结构化证据，本地同样可参与。

本地优先于共享，共享优先于 SEC；仅合并身份或事实证据匹配的事件，不按“同日同类型”直接吞掉独立节点。资产主体不同或精确时刻不同也不能轻率合并。

取消独立“宏观研究”模式。预期差信息进入通用卡片/详情，时间线、卡片、列表只改变布局。统计注明已加载、区间内与符合条件数，不把当前查询结果当完整日历覆盖。

卡片显示完整日期；实际事件日期与休市后映射的 K 线落点分开。原始时间保留在事件与详情，标记通过统一 alignEventMarkersToBars 对齐。

单击卡片选中，详情与定位 K 线分别操作。主图放大选中标记并保留颜色；同根 K 线聚合时选中事件成为主标签，其他数量保留。点主图标记选中对应卡片，滚动到可见位置。关闭详情不清除选择，也不自动修改用户的图层与筛选。

## 事件包与个性化显示

- 本地包有稳定 id、name、version、importedAt、enabled、可选默认色与 symbols。
- 按文件设置、当前资产、全部资产；文件 pack.symbols 可限定多个资产。
- 导入先预览，展示错误与已有 ID；确认后同包同 ID 更新，保留其他事件。
- 支持包开关、导出、删除并备份。旧 v1 存储保留为备份，新版读入 v2 包。
- 支持来源开关、类型配色、单事件配色、单事件是否上图和文字开关。
- 颜色优先级：个人单事件 > 个人类型规则 > 事件 color > 包默认 > 系统默认。文件已给事件色时，包默认色只补未指定颜色的事件。
- 个人覆盖保存在浏览器偏好，不改共享事实；预期差不覆盖显式颜色。
- 手机与桌面共享入口与规则；工具栏允许换行和滚动，导入预览适应窄屏。

## 部署与后续边界

应用代码按正常分支/PR/CI 发布；本地文件和数据库显示元数据整理不等于前端代码已部署。无需 db:migrate。

没有新增数据供应商、自动来源真实性认证、历史首发快照或投资预测能力。进一步完善云端持续采集、证据补全与事件修订账本，应继续沿用已有 adapters、订阅与 writer，不能用本次显示字段冒充历史可见性。

## 左侧来源分页（2026-10-18 补充）

事件管理器左侧上下排列「系统事件」「用户事件」，桌面与手机保持相同入口。系统页管理共享库/SEC 来源及资产关联；用户页管理 Skill 下载、本地导入、显示范围、事件包启停/导出/删除。两页分别列出本类卡片；页签切换不修改来源开关，主图仍合并两类已启用事件。点图上事件时自动切换到对应管理页。

未指定颜色时系统默认 #0369A1（蓝）、用户默认 #7C3AED（紫）；文件事件色、包默认色、个人颜色规则继续优先，不覆盖已有自定义颜色。两类事件分别保存搜索、类型、重要性、关联标签、上图开关、视图与颜色设置。重置、导入只改变当前来源；切换资产只套用系统页默认关联，用户页偏好保持不变。旧共用的内容与显示偏好首次读取时复制为两份；旧资产/地区条件此前只限制系统查询，不带入用户页。后续独立保存。两类分别筛选后再去重、合并上图，过滤掉的私人注释不会压掉仍符合条件的系统事件。统计显示本类区间内、排除与区间外数量；页签计数仅统计各自符合条件的事件。
